1. Go to *Point of Sale > Configuration > Settings* and select the register.
2. Under *PoS Interface*, enable *Log in with Employees* and set which employees have basic
   rights.
3. *Cashiers Close the Register*, right below, is ticked. Untick it on the registers where the
   closing stays with the manager, and save.
4. Reload the register page if a session is already open: the setting is read when the
   register loads.

An employee with basic rights now opens the menu and finds *Close Register*. With *Cash
Control*, a difference above the authorized amount still needs a manager to close.
