Overview

Customers often send their order, or the changes to it, as a spreadsheet. This module lets the salesperson export the lines of a sales order to Excel and import them back into the same order, with the standard Odoo export and import tools.

Order lines button: the Order lines smart button on the sales order opens the list of its lines (Order Lines: order, product, description, quantity, unit price). From this list the lines are exported with the standard Export, and a file is loaded with Import records; the imported lines go into this order.

Import into an empty order: when the order has no lines yet, every row of the file becomes a new line of the order.

Import into an order with lines: when the order already has lines, each row updates the existing line with the same product (quantity, price and the other imported columns). The product is recognized by the internal reference between square brackets ([CODE] Name, as in the export) or, failing that, by its exact name. Rows with a product that is not found or is not on the order are skipped. A row that has the ID (or External ID) column filled in updates exactly that line, and two rows with the same ID are an error, as is an ID that is not a line of this order (a line deleted after the export, or the file of another order). When the product is on several lines, the Description column picks the line; if the row still matches several lines, or the file has more rows for a product than the order has lines, the import stops with an error on that row instead of updating an arbitrary line. The lines named by an ID are taken first, so each line of the order is updated by one row at most.

Price formula hook: the use_specific_price_formula method is called on the imported unit prices of a new order, so a customer-specific module can apply its own price rule.

Limitations

  • When the order already has lines, a row for a new product is skipped without a message; it cannot add a line.
  • If the order has two lines with the same product and the same description, the file must have the ID column (export the lines with it) to update them.
  • Without the Order lines button, the order is read from the first row of the Order Reference column, by its reference (S00039) or its database id.
Usage
  1. Open the sales order (Sales > Orders > Quotations or Orders) and click the Order lines smart button. It opens the Order Lines list of this order only.
1 Quotation form with the product [SC-01] Scaun birou on two lines, described Scaun birou - negru and Scaun birou - gri, and the Order lines button highlighted
2 Order Lines list of the quotation with the columns Order Reference, Product, Description, Quantity and Unit Price
  1. To send the lines to the customer, select all the lines and click Actions > Export. Tick I want to update data (import-compatible export), add the External ID field (Description is already listed), remove the two Analytic lines/... fields and click Export. In this mode the file headers are the technical field names (id, product_id, name, product_uom_qty...): the customer changes only the values. The id column links each row to its line, even when the product is on several lines.
3 Export Data dialog in import-compatible mode, with Description and External ID among the fields to export and no analytic fields
  1. To load the customer's file, open the gear menu next to the Order Lines title, choose Import records and upload the file. Check that each file column is matched with the right Odoo field (Product, Quantity, Description...), then click Test.
4 Import a File screen with the Product and Quantity columns of the customer file matched to the Product and Quantity fields
  1. Test changes nothing. If a product is on several lines of the order and the file has neither the External ID nor a Description that picks the line, the test stops with an error next to the Product column. Import the file exported with the External ID, or add the Description column, and test again.
5 Import test error: the product is on 2 lines of the order, so the row cannot be matched to a single line
  1. Click Import. Each row updates its line, and the order totals are recomputed.
6 Quotation after the import: the two chair lines have the quantities 10 and 4 and the table line 3

How the rows are matched when the order already has lines:

  • a row with an External ID (or database ID) updates exactly that line; two rows with the same ID, or an ID that is not a line of this order (deleted line, file of another order), are an error;
  • otherwise the row updates the line with the same product, among the lines not taken by another row; when the product is on several of them, the Description column picks the line;
  • a row that still matches several lines, or a product with more rows than order lines, is reported as an error and the order is not changed;
  • a row with a product that is not on the order is skipped.

When the order has no lines yet, every row of the file becomes a new line of the order.
