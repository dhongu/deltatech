# Features

- 🚀 **Order Lines at the Top of Sale Orders**
  The module adds an "Order Lines" section at the top of each sale order, making it easy to view and manage all related lines in one place.
- 📥 **Import Purchase Lines from Excel**
  Effortlessly import purchase order lines directly from Excel files using Odoo's standard import tool, allowing quick bulk uploads and updates for each specific sale order.
