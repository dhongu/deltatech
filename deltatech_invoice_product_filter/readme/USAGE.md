1. Go to **Accounting > Customers > Invoices** (or **Vendors > Bills**).
2. In the search bar, type the name (or part of the name) of a product.
3. Odoo will match it against the new **Product** search field added next to the customer filter, returning all invoices/bills that contain a line with that product, so you no longer need to open each invoice to check its lines.
