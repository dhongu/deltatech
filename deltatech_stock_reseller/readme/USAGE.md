1. Go to **Sales > Reporting > Location Stock**.
2. In the wizard, select the **Source Location** to report on.
3. Optionally pick a **Partner** (its pricelist is filled in automatically) or set the **Reseller Price List** directly, to compute a resale price for each product.
4. Optionally enable **Show text instead of stock** and set two quantity thresholds with their own text (e.g. "Low stock", "Limited stock", "Stock") — quantities will be shown as these labels instead of numbers.
5. Click **Apply** to generate the report: a list of all products with free quantity greater than zero in that location, their category, quantity (or quantity text), list price and computed reseller price.
6. Leave **Refresh Report** checked to recompute from scratch each time, or uncheck it to reuse a previously generated report for the same location.
