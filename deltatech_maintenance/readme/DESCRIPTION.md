Maintenance and Stock Integration Extension
==========================================

This module extends Odoo's standard maintenance functionality by providing deeper integration with inventory management. It is designed for businesses that need to track stock movements (such as spare parts or tool transfers) associated with equipment maintenance and repair tasks.

Key Features
============

1.  **Maintenance-Related Stock Transfers**:
    *   Adds specialized views and fields to link **Stock Pickings** (Transfers) directly to maintenance requests.
    *   Allows maintenance teams to easily track the movement of parts or equipment required for repairs.

2.  **Unified Equipment and Inventory View**:
    *   Features an enhanced equipment form that provides visibility into associated stock operations.
    *   Improves the traceability of components used in maintenance activities.

3.  **Refined Security Model**:
    *   Introduces a dedicated security model for managing access to maintenance-related inventory records.

Usage
=====

1.  Navigate to **Maintenance > Equipment** or **Maintenance > Maintenance Requests**.
2.  Open or create a maintenance request.
3.  Locate the **Stock Pickings** tab or button (added by the module).
4.  Create or view transfers for the parts needed for the maintenance task.
5.  All stock movements will be linked to the specific maintenance record for complete logistical and historical tracking.
