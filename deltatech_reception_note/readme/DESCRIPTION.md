Batch Reception Note Management
==============================

This module provides a specialized tool for managing batch reception notes within Odoo's stock and purchase modules. It is designed to streamline the process of receiving multiple items or handling bulk reception documentation.

Key Features
============

1.  **Batch Reception Processing**:
    *   Adds a dedicated wizard for creating and managing reception notes in bulk.
    *   Allows users to group multiple stock pickings or purchase orders into a single reception note for easier tracking and documentation.

2.  **Integrated Stock Workflow**:
    *   Seamlessly integrates with the `purchase_stock` module to ensure consistent data flow between procurement and warehouse operations.
    *   Provides specialized views and reports for summarized reception information.

3.  **Enhanced Documentation**:
    *   Generates comprehensive reception documents that can be used for internal auditing and vendor verification.

Usage
=====

1.  Navigate to **Purchase > Orders** or **Inventory > Operations > Transfers**.
2.  Select the records you wish to include in a batch reception.
3.  Use the **Action** menu or the dedicated button (if available) to launch the **Reception Note** wizard.
4.  Configure the note details and confirm to generate the batch documentation.
5.  View and print the resulting reception note for logistical or accounting purposes.
