1. Configure a product as a **Kit** by creating a Bill of Materials for
   it with the type set to **Kit**.
2. Define the cost for each component product included in the kit.
3. Create a **Sales Order** and add the kit product to the order lines.
4. The system will automatically calculate and display the total cost
   price for the line based on the kit's components.
5. View the resulting margin to ensure profitability.
