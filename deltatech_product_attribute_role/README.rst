Business code often needs to know which attribute of a variant is *the*
variety, *the* size or *the* quality grade — to fill a lot, print a
delivery note or group a report. Finding that attribute by its name is
fragile: the name is translatable, consultants rename attributes, and
one client calls it ``Variety`` while another calls it ``Soi``.

This module adds a **Role** to product attributes. Modules that need an
attribute ask for it by role, and the attribute keeps working whatever
it is called.

Key business benefits:

- **Rename and translate freely.** Changing the name of an attribute, or
  the language it was entered in, no longer breaks lots, reports or
  printed documents that rely on it.
- **One attribute per role.** The database refuses a second attribute
  with the same role, so there is never a doubt which one a document
  reads.
- **Shared by several modules.** Each module adds the roles it needs;
  the field, the rule and the lookups are the same for all of them.

The module defines no roles of its own. It is a technical base for the
modules that add them (for example the apple grading modules, with
variety, quality and size).

Configuration
=============

Go to **Inventory → Configuration → Attributes**, open the attribute and
choose its **Role**. The list offers the roles added by the installed
modules; it is empty when no installed module adds any.

A role can be set on one attribute only. To move it, clear it on the
attribute that holds it first.

Usage
=====

In a module that needs a role, extend the selection and look the
attribute up by role:

.. code:: python

   class ProductAttribute(models.Model):
       _inherit = "product.attribute"

       attribute_role = fields.Selection(
           selection_add=[("variety", "Variety")],
           ondelete={"variety": "set null"},
       )

- ``product.attribute._get_attribute_by_role("variety")`` returns the
  attribute holding the role;
- ``product.product._get_attribute_value_by_role("variety")`` returns
  the variant's value for it;
- in domains, filter on ``attribute_id.attribute_role``, e.g.
  ``[('attribute_id.attribute_role', '=', 'variety')]`` on
  ``product.attribute.value``.

Users then pick the attribute's role in the attribute form, once per
database.
