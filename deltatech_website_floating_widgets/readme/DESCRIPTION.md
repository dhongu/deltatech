Features:

- Add customizable floating widgets to the right side of your website.
- Choose from a variety of icons (Phone, Email, WhatsApp, Facebook, Instagram, TikTok, etc.).
- Live icon preview in the backend for easy configuration.
- Support for different link types: URL, Phone (tel:), and Email (mailto:).
- Option to open links in a new tab.
- Note: For external links, ensure you include the protocol (e.g., `https://`). Otherwise, they will be treated as relative links within the Odoo website.
- Control visibility per device (Display on Mobile / Display on Desktop).
- Customizable button shapes: Circle, Square, or Rounded.
- Fully customizable colors for background and text.
- Manage the order of icons using sequence.
