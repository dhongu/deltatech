- Features:

  - Allows managing sales orders in multiple currencies
  - Provides the ability to set and display prices in different
    currencies
  - Maintains original currency information throughout the sales process
  - Handles currency conversion for accounting entries
  - Supports currency exchange rate differences when invoicing sales
    orders
  - Integrates with both sales and accounting modules
  - Improves reporting for sales in multiple currencies
