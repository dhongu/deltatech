Overview

Asks customers to rate the products they bought, by e-mail, a few days after the invoice.

Feedback e-mail per invoice. The Invoice: request feedback e-mail template lists the lines of a customer invoice, each with the product image, a link to the product page, the quantity and three rating links (Satisfied, Not satisfied, Highly Dissatisfied). Section and note lines are shown as headings.

Rating on the product. Each product line gets its own rating record on the product template, so a click on a rating link records the customer's rating for that product through the standard /rate page of Odoo.

Scheduled sending. The Request Feedback scheduled action (inactive at install) runs once a day and sends the e-mail for the customer invoices dated a given number of days ago, 3 by default. The delay is read from the sale.days_request_feedback system parameter (Settings > Technical > Parameters > System Parameters).

Manual sending. On customer invoices, Actions > Request feedback sends the e-mail for the selected invoices.

Links on the company website. When no website domain applies to the invoice, the links in the feedback e-mail are meant to use the company's Website address instead of web.base.url (once the sending is ported to 19.0). The other e-mails are not changed by the module and keep the standard Odoo base URL.

Limitations

  • On 19.0 the sending does not work: the code still calls xmlid_to_res_id and message_post_with_template, which no longer exist in Odoo, so both the scheduled action and Request feedback stop with an error. The subject, sender, recipient and language of the template also use the old ${...} syntax, which is no longer rendered.
  • The Email feedback after sale option and its e-mail template in Sales > Configuration > Settings are stored but not used: the e-mail always uses the module's own template, whatever the option says.
  • The scheduled action picks every customer invoice of that date, posted or not.
Usage

Note: on 19.0 the sending does not work yet (see Limitations in the description). The steps below show the configuration and the current behaviour.

  1. In Sales > Configuration > Settings, section Invoicing, tick Email feedback after sale. The Email Template Request Feedback field shows the module's template, Invoice: request feedback. The option is stored but not used by the sending.
1 Sales settings, Invoicing section: Email feedback after sale is ticked and Email Template Request Feedback is set to Invoice: request feedback
  1. The delay after the invoice date is the sale.days_request_feedback system parameter (Settings > Technical > Parameters > System Parameters, developer mode), 3 days by default.
2 System parameter form with Key sale.days_request_feedback and Value 3
  1. The Request Feedback scheduled action (Settings > Technical > Automation > Scheduled Actions) runs daily and is inactive at install. Once active, it sends the e-mail for the customer invoices dated that many days ago, whatever their state.
3 Request Feedback scheduled action on Journal Entry, run daily by OdooBot, with the Active toggle off and model.cron_request_feedback() in the Code tab
  1. To send it by hand, open a customer invoice, click the Actions gear and choose Request feedback (it also works on several invoices selected in the list).
4 Posted customer invoice INV/2026/00001 for Magazin Exemplu SRL with the Actions menu open and Request feedback highlighted
  1. On 19.0 this stops with the Oops! error dialog and no e-mail is sent: the code still calls Odoo functions that no longer exist.
5 The same invoice with the Oops! error dialog: Something went wrong, See technical details and Close
  1. The e-mail is the Invoice: request feedback template (Settings > Technical > Email > Templates): per invoice line, the product image, a link to the product page, the quantity and the three rating links. Its subject, sender, recipient and language still use the old ${...} syntax. Previewing it creates an empty rating on each product shown.
6 Invoice: request feedback template on Journal Entry, with the subject in the old ${...} syntax and the body Dear, Please take a moment to rate our products
