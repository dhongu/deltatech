This module adds a **Picking Status** badge to sale orders (Sales > Orders and Quotations), computed automatically — no configuration is needed.

- The badge shows **In Progress** while the order has no deliveries yet, or while any of its pickings is not Done/Cancelled.
- It switches to **Done** once all of the order's pickings are Done (or the order itself is cancelled).
- The badge appears on the order form (next to Payment Terms) and, as an optional column, on the quotations and orders list views.
- In the orders list search bar, use the **Done** / **In progress** filters to quickly find orders by delivery status.
