Overview

Sales orders and invoices should be issued to the company, with the invoice and delivery addresses taken from its contacts. This module keeps the selection lists on those documents to the right partners and lets you mark which address of a customer is proposed by default.

  • Company as customer
    The customer field of sales orders and invoices lists only partners without a parent company, so a contact person cannot be picked in place of the company.
  • Matching addresses
    On a sales order, the invoice address lists only the Invoice addresses of the chosen customer, and the delivery address only its Delivery addresses.
  • Default address
    A Contact Default checkbox on the invoice and delivery addresses marks the one that Odoo proposes on new documents. Ticking it clears the mark on the other addresses of the same type of that customer.
  • Green Invoice
    A Green Invoice checkbox on the customer form is for customers who prefer paperless invoices. When their invoice is sent, the PDF is no longer downloaded by default and the invoice is e-mailed instead; the PDF can still be downloaded by ticking it in the sending window.

The module depends on Sales, Contacts, Invoicing and Contact Personal Data (deltatech_contact). The restrictions are filters on the selection lists of the forms: records created by import or through the API are not checked.

Versions

19.0.1.1.2 (2026-11-11)

  • Apps Store page: a fuller description (what the module does, the problem it solves, its main functions, dependencies and limits). No change in behavior.

19.0.1.1.1 (2026-10-16)

  • Development status raised from Beta to Production/Stable: the module has been in production use at customers for a long time.

19.0.1.1.0 (2026-10-14)

  • "Green Invoice" works again, on the Odoo 19 sending flow: for a partner with the flag, sending an invoice no longer downloads the PDF by default (the Download sending method is replaced by e-mail). The PDF can still be downloaded by ticking it in the wizard. In 18.0 the flag unticked the download in the old wizard; the override was removed in 19.0.1.0.24 because that wizard field no longer exists.

19.0.1.0.24 (2026-10-02)

  • Remove the account.move.send override: it targeted _compute_checkbox_download, which does not exist in Odoo 19, so the "Green Invoice" flag on partners never did anything. The flag stays on the partner as an informative field (existing data is kept) and its help text no longer promises to block printing.

19.0.1.0.23 (2026-10-01)

  • Fix: address_get() no longer fails when called without address preferences (e.g. from event registrations).

19.0.1.0.22 (2026-09-29)

  • Own module icon, instead of the generic gears it had.
