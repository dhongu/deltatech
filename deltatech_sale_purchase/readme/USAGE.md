This module works automatically in the background; there is no menu or setting to configure.

- When a sale order that has already generated one or more purchase orders (via procurement rules) is cancelled, the module automatically finds and removes the corresponding lines from the related draft purchase orders, so no orphan purchase lines are left behind.
- If a quantity is reduced on the sale order instead of being fully cancelled, the linked purchase order lines are updated to match the new, lower quantity.
