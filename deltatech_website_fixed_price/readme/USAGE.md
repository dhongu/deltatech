No configuration is needed. Once installed, the module changes how the eCommerce shop displays prices coming from pricelist rules of type "Fixed Price":

- Go to **Sales > Configuration > Pricelists** and create/edit a pricelist rule with **Compute Price** set to **Fixed Price**.
- On the website shop and product pages, the fixed price will now show as a "discounted" price (the original list price struck through, the fixed price shown as the new price), even in cases where Odoo would normally hide this comparison (e.g. when the fixed price is higher than the list price).
