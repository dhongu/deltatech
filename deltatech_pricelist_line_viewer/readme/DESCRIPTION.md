This module adds a **Pricelist Lines** button to the pricelist form. The button opens all the rules
of that pricelist in a full list view, with the standard search, filters and grouping, which makes
large pricelists much easier to review and maintain than the **Sales Prices** tab of the form.

Key features:

- **Pricelist Lines** button on the pricelist form, opening the rules of the current pricelist only
  (columns Pricelist, Products, Min. Quantity, Price, Start Date, End Date; Currency, Based on and
  Apply On as optional columns);
- search on the rules by **Product**, **Category**, **Pricelist** and **Currency**;
- new rules created from the list get the current pricelist by default;
- the **Permit pricelist editing** group gives read, write, create and delete rights on pricelists
  and pricelist rules, so a user can manage prices without being a Sales Administrator.
