Features:

- Dynamically filters product attribute values on the website shop page
  based on the products currently displayed.
- Ensures that only relevant attribute values (those belonging to the
  visible products) are shown in the filter sidebar and off-canvas menu.
- Supports all standard Odoo attribute display types:

  - Select dropdowns
  - Radio buttons
  - Pills
  - Multi-select (Checkboxes)
  - Color attributes

- Automatically updates filters when searching or navigating categories.
- Optimized for performance by efficiently identifying active attribute
  values from the product template attribute lines.
- Compatible with Odoo's standard eCommerce layout and responsive
  off-canvas filters.
