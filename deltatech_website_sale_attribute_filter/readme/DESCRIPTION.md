Features:

- Dynamically filters product attribute values on the website shop page based on the products currently displayed.
- Ensures that only relevant attribute values (those belonging to the visible products) are shown in the filter sidebar and off-canvas menu.
- Supports all standard Odoo attribute display types:
    - Select dropdowns
    - Radio buttons
    - Pills
    - Multi-select (Checkboxes)
    - Color attributes
- Automatically updates filters when searching or navigating categories.
- Preserves the filter UI state (expanded attribute accordions, open mobile off-canvas panel, scroll position) across the page reload triggered on each selection, so the customer does not have to reopen the filters every time.
- Optimized for performance by efficiently identifying active attribute values from the product template attribute lines.
- Compatible with Odoo's standard eCommerce layout and responsive off-canvas filters.
