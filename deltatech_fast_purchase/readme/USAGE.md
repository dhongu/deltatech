On a purchase order form, three extra buttons let you collapse the usual confirm/receive/bill steps:

1. **Confirm, Receipt and Bill** — confirms the purchase order (if still in draft), validates all its stock transfers as fully received, then opens the wizard to create the vendor bill, all in a single click.
2. **Receipt and Bill** — same as above but for an order that is already confirmed: validates the receipt(s) and opens the bill wizard.
3. **Receipt Notice** — marks the related receipt(s) as "notice" (advice received, goods not yet physically in) and opens them, without validating the stock move; use it when you want to record that a delivery notice arrived before doing the actual reception.
