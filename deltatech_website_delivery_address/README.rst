Key Features
============

This module enhances the Odoo website's delivery management by providing
users with more control over their default delivery addresses.

Features:
---------

- Allows administrators to set a default delivery address for specific
  website users.
- Automatically pre-selects the preferred delivery address during the
  checkout process.
- Improves the speed and accuracy of online orders by reducing manual
  selection errors.
- Integrates seamlessly with the standard Odoo website checkout
  workflow.

Usage:
------

1. Go to Settings > Users & Companies > Users.
2. Open a website user's profile.
3. You will find a new section to configure the default delivery address
   for this user.
4. When the customer logs in and proceeds to checkout, this address will
   be selected by default.
