Deltatech Website Product Placeholder

Serve placeholder image for products without images

Odoo 19.0 Website OPL-1 Online • Odoo.sh • On-premise

Overview

This module allows you to configure a custom placeholder image for products that do not have an image set. Optimizes website performance by serving a single static or configurable URL for all products without images, which improves browser and CDN caching.

Key features: - Configurable placeholder image per website. - Fallback to a default static image if no custom image is configured. - Optimized QWeb image field converter to use the placeholder URL directly in HTML. - Improved SEO and page load speed by avoiding dynamic image generation for missing images.
