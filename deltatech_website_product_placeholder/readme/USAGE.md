1. Go to **Website > Configuration > Settings**.
2. In the **Product Placeholder** setting, upload the image you want to use as the default picture for products that have no image configured.
3. Save. From then on, any product (or product variant) without its own image will show this custom placeholder on the website instead of Odoo's generic placeholder — including in all the resized image variants (1920/1024/512/256/128) used across the shop.
4. If no image is configured for a website, a built-in static placeholder image is used as fallback, which also improves caching since the same static/URL is reused for every image-less product.
