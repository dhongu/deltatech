## 19.0.1.0.2 (2026-10-01)

- Removal priority is now recomputed when the product category or the location type changes (PRIORITY-001).
- Changing the `stock.removal_priority.default` parameter recomputes the quants that use the default priority.
- Archiving or restoring a putaway rule recomputes the priority of the affected quants (PRIORITY-002).
