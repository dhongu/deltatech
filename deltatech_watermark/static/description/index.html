Overview

Upload the company watermark once, in the settings, and let other modules use it where it is needed. This module stores the watermark image on each company and shows it in the General Settings. It does not change any page or document by itself: the Website Watermark Image module uses it to mark the product pictures of the online shop.

  • One watermark per company
    Each company keeps its own watermark image. In a multi-company database, the setting applies to the current company.
  • Set in General Settings
    The image is uploaded in the Companies section of the settings, with a preview.
  • Base for Website Watermark
    Website Watermark Image applies it to the product pictures of the shop when they are displayed, so the original images stay clean.
  • Lightweight
    It depends only on the standard settings (base_setup and web), so other modules can build on it without pulling in the website.

Configuration

  1. Go to Settings > General Settings, section Companies.
  2. Under Watermark image, upload the image to use as the company watermark.
  3. In a multi-company database, switch to each company and repeat, if the companies use different watermarks.

Screenshot from an earlier Odoo version, where the field was under Business Documents. In Odoo 19 it is in the Companies section.

Usage

This module only stores the watermark. To see it applied, install a module that uses it, such as Website Watermark Image, which marks the product pictures of the online shop.

When the Watermark image is empty, the modules that depend on it show the images unchanged.
