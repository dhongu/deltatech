Every sale order gets a new **Stage** field, computed automatically from the order state, delivery status and any postponed-delivery flag. No manual setup is needed; the stage is kept up to date as the order moves through confirmation and delivery.

- Possible stages: Placed, In Process, Request for Quotation, Waiting availability, Postponed, To Be Delivery, Pre advice, In Delivery, Delivered, Canceled, Returned.
- The stage is shown as a color-coded badge on the sale order list, the quotation list and the order form (next to the payment terms).
- In **Sales > Orders**, use the new filters **Placed**, **In process** and **To Be Delivery** (or search by customer phone/mobile) to quickly locate orders in a given stage.
- Customers see the same status as a colored badge on their **My Orders** and **My Quotations** pages in the website portal.
