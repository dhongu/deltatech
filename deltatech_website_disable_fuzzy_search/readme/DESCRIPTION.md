When fuzzy matching is on, the website search can find words that are close to the one typed. This module turns fuzzy matching off in the website search bar and in the product search of the online shop.

- **Search bar**: The search bar of the website no longer uses fuzzy matching, whatever the page asks for.
- **Shop search**: The product search of the online shop does not use it either.
- **Always on**: There is no setting or menu. Once installed, the change applies to every website, visitor and language of the database.

The module depends on eCommerce (`website_sale`) and adds no views, data, menus or access rules: it only changes how those two searches are started. Because there is no setting, it cannot be switched off for one website; uninstall the module to get fuzzy matching back.
