Nothing has to be configured — every attribute is searchable once the module is
installed.

To leave one out, go to **Inventory → Configuration → Attributes**, open the attribute
and clear **Searchable**. Use it for attributes whose values are short or numeric enough
to match almost anything (a quality grade named `1/5`, a size named `2`), which would
otherwise push the variants you are looking for out of the result page.

The flag is per attribute, not per value, and it changes only what the search looks at —
the values keep working everywhere else.
