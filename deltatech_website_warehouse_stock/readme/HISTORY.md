## 19.0.0.0.5 (2026-10-21)

- Design options per website (Website > Configuration > Settings, Warehouse Stock Design):
  style (badges as before, list with icons, card, warehouse selector with a "Check stock"
  button), message at zero stock ("Out of stock" or "On order" with an optional note),
  quantity display (exact below the threshold or status only) and theme colors (badges
  tinted on the page colors, readable on dark themes). The defaults keep the previous look.
- The block is no longer shown when no warehouse is displayed on the website; the
  template is named "Warehouse Stock" in the Customize menu (was "Alternative code").
- The quantity below the threshold is shown without decimals when whole (4, not 4.0).
