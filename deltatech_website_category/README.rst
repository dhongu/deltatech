Key Features
============

This module enhances the management of eCommerce public categories on
the Odoo website.

Features:
---------

- Provides the ability to archive public product categories.
- Helps maintain a cleaner website navigation by removing obsolete or
  temporary categories without deleting them.
- Allows for easy restoration of archived categories if they are needed
  again in the future.
- Improves overall website category organization and user experience.

Usage:
------

1. Navigate to Website > Configuration > eCommerce Categories.
2. Select one or more categories that you want to archive.
3. Use the archive/unarchive action on the category form to hide or show
   it on the website.
4. Archived categories will not appear in the shop menu or as filter
   options on the product list page.
