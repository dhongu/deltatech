Features:

- disables the option to create new items without editing them, for prevention of empty products, contacts, etc.
- applies to every many2one widget (plain, avatar, barcode, reference); **Create and edit...** stays available.

Odoo Online
===========

The module contains no Python code, only one JavaScript file. Besides Odoo.sh and
on-premise installations, it can be used on Odoo Online (Custom plan): download the zip
and load it from **Apps > Import Module**.
