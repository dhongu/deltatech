This is a purely technical module with no configuration or menu of its own. Once installed, it patches every **Many2one** field in the backend so that typing a new value and pressing Enter no longer offers "Create <value>" as a quick option — users are always sent to the full **Create and edit...** form instead. This prevents accidentally creating incomplete/empty products, contacts, and other records straight from a dropdown. No settings toggle exists; the behavior applies globally as soon as the module is installed.
