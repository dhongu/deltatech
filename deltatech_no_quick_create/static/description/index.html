Overview

Features:

  • disables the option to create new items without editing them, for prevention of empty products, contacts, etc.
  • applies to every many2one widget (plain, avatar, barcode, reference); Create and edit... stays available.

Odoo Online

The module contains no Python code, only one JavaScript file. Besides Odoo.sh and on-premise installations, it can be used on Odoo Online (Custom plan): download the zip and load it from Apps > Import Module.

Usage

  1. Install the module, or on Odoo Online import the zip from Apps > Import Module (Custom plan, developer mode), then reload the page. There is nothing to configure.
  2. Open Contacts > Contacts, click New and type a company name that does not exist yet in the company field under the name (building icon, placeholder Company Employer). The dropdown no longer offers Create "...": only Create and edit... is left. Every many2one field behaves the same way (customer, product, category, salesperson).

  1. Click Create and edit...: the Create Related Company dialog opens with the typed name already filled in. Complete the address and tax ID, then click Save.

Versions

  • Data-only module: the empty __init__.py files (module and tests/) were removed, so the module has no Python code at all. It can be installed on Odoo Online (Custom plan) as a zip from Apps > Import Module, as well as on Odoo.sh and on-premise.
  • Odoo Apps does not mark data-only modules as available on Odoo Online, so the module name, the summary, the banner and the Apps Store page now say it: "No Quick Create (importable, Odoo Online)".
