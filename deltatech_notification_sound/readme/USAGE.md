1. Install the module — no extra UI or configuration is added besides one preference.
2. Use Odoo normally: a short sound plays automatically whenever a backend notification pops up, with a different sound per type (success, warning, error/danger, info).
3. To disable sounds for your own account, go to **Settings > Users & Companies > Users**, open your user, and uncheck **Enable notification sounds** in the Preferences tab, then reload the page so the session picks up the new value.
4. Notes: browser auto-play policies may keep the very first notification silent until you click or type somewhere on the page, and mobile browsers may mute auto-played audio by default.
