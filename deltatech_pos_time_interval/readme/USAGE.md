1. Go to **Point of Sale > Reporting**, then open the **Time Period Wizard** menu item.
2. Fill in the **First Period** date range and the **Second Period** date range.
3. Click **Compute**. The system copies the matching rows from the Point of Sale Orders report into a temporary comparison report and opens it as a pivot table.
4. The pivot table shows the two periods side by side as columns (with POS configuration in rows and order count, quantity and total price as measures), making it easy to compare sales between the two intervals.
