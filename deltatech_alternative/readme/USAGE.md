1. Go to **Inventory/Sales > Configuration > Settings** and enable **Alternative Search** to allow searching products by their alternative codes; optionally set the search **Limit** and the **Minimum Length** of the typed text before alternative codes are searched.
2. On a product template or variant, open the **Alternative Codes** tab to add one or more alternative/cross-reference codes (e.g. supplier or customer codes). Mark a code as **Hidden** to exclude it from the combined `alternative_code` display. Use the **Used For** field to document the product's typical use.
3. Once enabled, typing an alternative code in the product search box (on Sale Order lines, Purchase Order lines, or Stock Move/Picking lines) will also match products, in addition to the standard name/reference search.
4. If a typed code is not found on any existing product, the module also looks it up in the **Product Catalog** (`product.catalog`) master-data list and automatically creates a new product from the matching catalog entry.
5. A daily scheduled action automatically splits `product.alternative` records whose code field contains several codes separated by `;`, `,` or spaces into individual records; no manual action is needed.
