Key Features
============

This module provides more flexibility during the stock reception process by allowing users to update the list price of products directly from the picking view.

Features:
---------

- Allows manual editing of the list price for products during the reception process.
- Adds specific fields in the stock picking view to handle price adjustments.
- Synchronizes the new prices with the product master data upon confirmation.
- Includes configuration settings to enable or disable this feature as needed.

Usage:
------

1. Navigate to Inventory > Receipts.
2. Open a stock picking in "Draft" or "Ready" state.
3. You will find fields that allow you to modify the product price for the lines being received.
4. After finalizing the reception, the product prices will be updated in the system based on the entered values.
