Features
========

This module allows users to edit the currency exchange rate directly on invoice documents.
It provides more flexibility when dealing with foreign currency invoices that may have a specific exchange rate different from the standard daily rate.

Key Features
------------

- Manual edit of the currency exchange rate on Customer Invoices and Vendor Bills.
- Automatic recalculation of accounting amounts based on the user-defined rate.
- Support for multi-currency environments in Odoo.
- Ensures consistency between the invoice document and the recorded financial amounts.

Usage
-----

- Open an invoice in draft state.
- Locate the currency and exchange rate fields.
- Edit the exchange rate as needed.
- The amounts in company currency will be updated according to the new rate.
