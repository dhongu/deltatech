Deltatech Accounting Extensions
==============================

This module provides a suite of enhancements to Odoo's standard accounting and invoicing models. It's designed to streamline the financial workflow for businesses by providing better invoice visibility and more flexible configuration options.

Key Features
============

1.  **Extended Invoice Visibility**:
    *   Adds extra fields and specialized columns to the customer invoice and vendor bill views.
    *   Improves the list view for invoices with more relevant information for daily accounting operations.

2.  **Flexible Journal and Account Handling**:
    *   Provides additional configuration options for accounting journals and individual accounts.
    *   Includes a refined security and permission model for sensitive accounting fields.

3.  **Cross-Document Synchronization**:
    *   Ensures that accounting data flows accurately between related documents (e.g., from Invoices to Payments).
    *   Includes specific logic for managing period closures and accounting date overrides.

Usage
=====

1.  Navigate to **Accounting > Customer Invoices** or **Accounting > Vendor Bills**.
2.  Open an invoice record to view the enhanced layout and additional fields.
3.  Go to **Accounting > Configuration > Journals** to explore the new configuration options provided by the module.
4.  Configure the **General Settings** for Accounting to enable or disable specific features of the extension.
