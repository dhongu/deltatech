Key Features
============

This module introduces a new snippet for the Odoo eCommerce website,
allowing for advanced product attribute filtering.

Features:
---------

- Adds a customizable attribute filter snippet to the website's
  drag-and-drop editor.
- Allows for the selection of specific attributes to be displayed in a
  dropdown for quick filtering.
- Enhances the customer's shopping experience by providing direct links
  to filtered product categories.
- Includes options for icons and text customization for each attribute
  item.

Usage:
------

1. Access the website's edit mode.
2. Search for the "Attribute Value Filter" snippet and drag it into the
   desired section.
3. Configure each filter item by selecting the desired attribute and
   customizing the icons and text.
4. Customers can then use these dropdowns to quickly jump to the shop
   results page with the selected filters applied.
