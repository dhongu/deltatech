The **Sale Order Activity Report** module provides detailed tracking and
reporting of user activities on Sales Orders. It captures every change,
message, and stage transition, allowing managers to monitor team
productivity and order progress through comprehensive pivot and graph
views.

Features
========

- **Automatic Activity Logging**: Every change made to a Sale Order is
  automatically recorded, including field updates, status changes, and
  button clicks (Confirm, Cancel, Lock, etc.).
- **Detailed Change Tracking**: The system logs both the old and new
  values of changed fields, providing a clear audit trail.
- **Special Event Capture**:

  - **AWB Generation**: Tracks when shipping labels are generated.
  - **Chatter Messages**: Records messages posted in the order's
    chatter.
  - **Tag Changes**: Monitors updates to order tags.

- **Stage Monitoring**: Specifically tracks custom stages (e.g., Placed,
  In Process, Waiting availability, In Delivery, Delivered) to measure
  process efficiency.
- **Comprehensive Reporting**:

  - **Pivot View**: Analyze activities by user, stage, and date.
  - **Graph View**: Visualize activity distribution across different
    stages.
  - **Search & Filters**: Easily find activities for "Today", "This
    Month", or "This Year".

- **User-Based Analysis**: See exactly which user performed which action
  and when.
