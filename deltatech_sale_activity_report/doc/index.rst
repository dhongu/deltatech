Sale Order Activity Report
=========================

The Sale Order Activity Report module provides detailed tracking and reporting of user activities on Sales Orders.

Configure the Sale Order Activity Report module
-----------------------------------------------

The module is installed from the Apps menu by searching for "Sale Order Activity Report".

Operation of the module
-----------------------

Every change made to a Sale Order is automatically recorded, including field updates, status changes, and button clicks (Confirm, Cancel, Lock, etc.).

To access activity reports:

1. Go to **Sales > Reporting > Activity Records**.

|1. Reporting Menu.png|

2. By default, you'll see a list of all activities for the current month.

3. Use the **Pivot** view to analyze user performance by stage and date.

|2. Pivot View.png|

4. Use the **Graph** view for a visual breakdown of order statuses.

5. Click on any record to see the **Activity Log**, which contains the exact field changes.

|3. Activity Log.png|
