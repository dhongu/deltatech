On a sales order form, extra buttons let you collapse the usual confirm/deliver/invoice steps:

1. **Confirm, Deliver and Invoice** — confirms the sales order (if still in draft/sent), validates its delivery once all products are available, then opens the "Create Invoice" wizard, all in one click.
2. **Deliver and Invoice** — same as above but for an order that is already confirmed: validates the delivery(ies) and opens the invoicing wizard.
3. **Deliver Notice** — marks the related delivery/deliveries as "notice" (advice sent, goods not yet physically shipped) and opens them, without validating the stock move; use it to record that a delivery notice was issued before the actual shipment happens.

Note: the delivery buttons require the picking's products to be fully available; otherwise an error is raised asking to complete availability first.
