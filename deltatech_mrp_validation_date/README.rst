Tracks the exact date when a manufacturing order is validated (marked as
done), giving production managers a reliable audit trail of order
completion times.

**Key features:**

- Adds a **Validation Date** field to the manufacturing order form,
  automatically populated when the operator clicks **Mark as Done**.
- The field is read-only — it is set by the system and cannot be changed
  manually, ensuring data integrity.
- Works alongside the standard MRP scheduling fields (scheduled date,
  date finished) to provide a complete production timeline.

Usage
=====

Using the Validation Date
-------------------------

1. Open **Manufacturing > Manufacturing Orders** and select or create a
   production order.
2. Process the order normally (confirm, produce components, set
   quantities).
3. Click **Mark as Done** to complete the order.
4. The **Validation Date** field (displayed in the order header, next to
   the Responsible user) is automatically set to today's date.
5. The field is read-only — it reflects the actual date the order was
   validated and cannot be edited manually.
