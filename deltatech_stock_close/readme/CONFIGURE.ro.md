1. Instalați modulul; are nevoie de fișa de magazie din localizarea românească
   (`l10n_ro_stock_report`).
2. Stabiliți ce mișcări de stoc sunt închise (de exemplu toate mișcările unui an fiscal închis) și
   debifați pe ele **Valuation Active**, prin import (*Inventar > Raportare > Istoric mișcări*, export
   și import al câmpului) sau printr-un script.
