Adds the product manufacturer to the **Sale margin report** (profit analysis) of
*Sale Commission*: search by manufacturer and **Group By > Manufacturer**, so the
sales, cost and profit can be read per manufacturer.

The manufacturer is the one set on the product (*Products Extension*). The module
installs by itself when both *Sale Commission* and *Products Extension* are
installed on a new database; on an existing database install it from Apps.
