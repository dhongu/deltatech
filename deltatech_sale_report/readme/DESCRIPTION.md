Features: This module will add new fields to the sale order report:

- (17.0.0.0.0) adds the email of the partner to the report
- (17.0.0.0.1) adds order (total amount(without delivery) / order count) and product mean value (total amount(without delivery) / invoiced product quantity) to the report
- (17.0.0.0.4) adds Is delivery and transport value to the report
- (17.0.0.0.5) adds the first supplier of the product to the report
