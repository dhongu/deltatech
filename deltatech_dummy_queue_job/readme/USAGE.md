This is a technical compatibility shim, not a module with a user-facing screen. It adds a no-op `with_delay()` method to all models so that code written to use the `queue_job` module (`record.with_delay().some_method()`) still runs, executing immediately and synchronously instead of being queued. Install it only on databases where `queue_job` is not installed but some other module calls `with_delay()`; no configuration is required.
