Gives every eCommerce category its own **SVG icon** and shows it in the
shop.

- New field **Icon (SVG)** on the eCommerce category, with a live
  preview on the category form.
- The categories shown on top of the shop (filmstrip) display the icon
  instead of the category image.
- The left category list shows a small icon before the category name.
- Option **Category Icons in List** (Website > Configuration > Settings,
  Shop - Products) decides which categories of the category list show an
  icon:

  - **Main categories only** (default): an opened branch lists its
    subcategories as plain text, which keeps the list light and easy to
    read;
  - **All categories**: every category with its own icon shows it;
  - **All categories, inherit from parent**: a subcategory without its
    own icon shows the icon of its closest parent that has one.

- In the categories on top of the shop, usually the subcategories of the
  opened category, a category without its own icon or image shows its
  closest parent's icon instead of the empty placeholder.
- Icons drawn with ``currentColor`` take the color of the category link,
  so they follow the theme, the hover color and the active category.
- The icon is checked when saved, so it is safe to show on public pages:
  only flat shapes are accepted (``path``, ``rect``, ``circle``,
  ``ellipse``, ``line``, ``polyline``, ``polygon``, ``g``), with colors,
  numbers and ``transform``. Scripts, styles, links, external images and
  event handlers are refused with a message that says what to fix. The
  drawing needs a ``viewBox``; its size comes from the page.

The icons can be drawn by hand, generated in bulk by Terrabit in the
style of your shop, or written by any tool through the ``icon_svg``
field (import, XML-RPC).

Usage
=====

1. Go to **Website > eCommerce > Categories** and open a category.
2. Paste the SVG markup in **Icon (SVG)** and save. The preview shows
   the icon.
3. The left category list of the shop shows the icon before the name of
   the main categories.
4. To show the icons on top of the shop, open the shop in the website
   editor and turn on the categories filmstrip at the top of the page.
5. To choose which categories of the list show an icon (main categories
   only, all, or all with the parent's icon as fallback), set **Category
   Icons in List** in Website > Configuration > Settings.

Changelog
=========

19.0.1.2.0 (2026-10-17)
-----------------------

- The Boolean **Inherit Category Icons** becomes the choice **Category
  Icons in List**: main categories only (new default, as on agrotrac.ro:
  an opened branch stays plain text and the page light), all categories,
  or all categories with the parent's icon as fallback. A website that
  had the Boolean set gets the last choice (migration).
- Categories on top of the shop (filmstrip) without their own icon or
  image now show their closest parent's icon instead of the empty
  placeholder.

19.0.1.1.0 (2026-10-17)
-----------------------

- New website option **Inherit Category Icons**: in the category list, a
  subcategory without its own icon shows the icon of its closest parent
  that has one (new computed field ``icon_inherited_html``).
- ``currentColor`` icons are documented and tested: they take the color
  of the category link.

19.0.1.0.1 (2026-10-17)
-----------------------

- The icon and the name in the category list now sit in an inner flex
  span, instead of making the link itself a flex box. Themes that
  restyle the link (Agroamat forces ``display: block !important`` on it)
  no longer push a long name's second line under the icon.

19.0.1.0.0 (2026-10-17)
-----------------------

- First release: SVG icon on eCommerce categories, checked against an
  allow-list when saved, shown in the left category list and in the
  categories filmstrip.
