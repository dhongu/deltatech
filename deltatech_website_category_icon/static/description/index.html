Overview

Gives every eCommerce category its own SVG icon and shows it in the shop.

  • ✓
    New field Icon (SVG) on the eCommerce category, with a live preview on the category form.
  • ✓
    The categories shown on top of the shop (filmstrip) display the icon instead of the category image.
  • ✓
    The left category list shows a small icon before the category name.
  • ✓
    Option Category Icons in List (Website > Configuration > Settings, Shop - Products) decides which categories of the category list show an icon:
    • Main categories only (default): an opened branch lists its subcategories as plain text, which keeps the list light and easy to read;
    • All categories: every category with its own icon shows it;
    • All categories, inherit from parent: a subcategory without its own icon shows the icon of its closest parent that has one.
  • ✓
    Option Category Icon Order (same settings page) decides what the shop shows for a category, the first one found: SVG, image, none (default), Image, SVG, none, SVG, image, first product image or Image, SVG, first product image. SVG is the category's icon, else its closest parent's; first product image is the picture of the first published product of the category or its subcategories. The same order applies to the filmstrip, the left category list, the block Category Icon Grid and, when installed, the category menu and subcategory list of Website Shop Blocks.
  • ✓
    Website block Category Icon Grid, to drag on any page (home page, landing pages): the main categories or categories chosen by hand, with their icon and name, each linking to its shop page. The categories are rendered on each visit, so the page always shows the current icons; the maximum number and the icon size are options of the block. 6 columns on desktop, 2 on phones.
  • ✓
    Icons drawn with currentColor take the color of the category link, so they follow the theme, the hover color and the active category.
  • ✓
    The icon is checked when saved, so it is safe to show on public pages: only flat shapes are accepted (path, rect, circle, ellipse, line, polyline, polygon, g), with colors, numbers and transform. Scripts, styles, links, external images and event handlers are refused with a message that says what to fix. The drawing needs a viewBox; its size comes from the page.

The icons can be drawn by hand, generated in bulk by Terrabit in the style of your shop, or written by any tool through the icon_svg field (import, XML-RPC).

Usage

  1. Go to Website > eCommerce > Categories and open a category.
  2. Paste the SVG markup in Icon (SVG) and save. The preview shows the icon.
  3. The left category list of the shop shows the icon before the name of the main categories.
  4. To show the icons on top of the shop, open the shop in the website editor and turn on the categories filmstrip at the top of the page.
  5. To choose which categories of the list show an icon (main categories only, all, or all with the parent's icon as fallback), set Category Icons in List in Website > Configuration > Settings.
  6. To choose what a category shows (its icon, its image or the picture of its first product, and in which order), set Category Icon Order in Website > Configuration > Settings.
  7. To show the categories with their icons on any page (the home page, a landing page), open the page in the website editor and drag the block Category Icon Grid from the Catalog group. In its options, choose the main categories or pick categories by hand, the maximum number and the icon size.

Versions

19.0.1.4.0 (2026-10-22)

  • New website option Category Icon Order (Website > Configuration > Settings): what the shop shows for a category, the first one found. SVG, image, none (default); Image, SVG, none; SVG, image, first product image; Image, SVG, first product image. SVG is the category's icon, else its closest parent's; first product image is the picture of the first published product of the category or its subcategories, in the shop order.
  • One helper, tb_category_visual, decides for every place: the filmstrip, the left category list (which now also shows the image when the order finds one, in an icon-sized box; Category Icons in List still decides which categories show something) and the block Category Icon Grid. Website Shop Blocks uses it too when this module is installed.
  • Filmstrip: the image is loaded by URL instead of being inlined in the page. A subcategory with its own image but no icon, under a parent with an icon, now shows the parent's icon with the default order (the parent's icon is part of the SVG step); choose Image, SVG, none to show its image first.

19.0.1.3.0 (2026-10-19)

  • New website block Category Icon Grid (Catalog group of the editor): a grid of eCommerce categories with their icon and name, each linking to its shop page. Options: main categories or categories chosen by hand (kept in the chosen order), maximum number (1 to 48) and icon size. The page keeps only the options; the categories are rendered by the server on each visit, for the current website, so the block follows the icons of the database. Categories without an icon show only their name. 6 columns on desktop, 3 on tablets and 2 on phones.

19.0.1.2.0 (2026-10-17)

  • The Boolean Inherit Category Icons becomes the choice Category Icons in List: main categories only (new default, as on agrotrac.ro: an opened branch stays plain text and the page light), all categories, or all categories with the parent's icon as fallback. A website that had the Boolean set gets the last choice (migration).
  • Categories on top of the shop (filmstrip) without their own icon or image now show their closest parent's icon instead of the empty placeholder.

19.0.1.1.0 (2026-10-17)

  • New website option Inherit Category Icons: in the category list, a subcategory without its own icon shows the icon of its closest parent that has one (new computed field icon_inherited_html).
  • currentColor icons are documented and tested: they take the color of the category link.

19.0.1.0.1 (2026-10-17)

  • The icon and the name in the category list now sit in an inner flex span, instead of making the link itself a flex box. Themes that restyle the link (Agroamat forces display: block !important on it) no longer push a long name's second line under the icon.

19.0.1.0.0 (2026-10-17)

  • First release: SVG icon on eCommerce categories, checked against an allow-list when saved, shown in the left category list and in the categories filmstrip.
