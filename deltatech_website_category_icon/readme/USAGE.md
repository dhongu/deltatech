1. Go to **Website > eCommerce > Categories** and open a category.
2. Paste the SVG markup in **Icon (SVG)** and save. The preview shows the icon.
3. The left category list of the shop shows the icon before the name of the
   main categories.
4. To show the icons on top of the shop, open the shop in the website editor and
   turn on the categories filmstrip at the top of the page.
5. To choose which categories of the list show an icon (main categories only,
   all, or all with the parent's icon as fallback), set **Category Icons in
   List** in Website > Configuration > Settings.
