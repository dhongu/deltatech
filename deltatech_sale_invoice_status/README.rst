-  Features:

   -  Manage Sale Order Invoice Status based on delivery for consumable
      products.
   -  If products and services are present in the sale lines and no
      products are delivered, the invoice status will be set to "No".
   -  If only services are present in the sale lines, the invoice status
      will be set to "To invoice".
