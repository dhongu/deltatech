1. Give the users the **Safety officer** or **Safety manager** access right (Settings → Users).
2. Go to **Safety → Events → New**, choose the type, date, location and describe the event. For an
   injury, select the injured employee, partner or type the name; tick *Commuting accident* when it
   happened on the way to or from work.
3. In the **Root cause** tab write the cause, then add the **Corrective actions** with responsible
   and deadline. Each responsible receives a To-Do activity.
4. Mark each action **Done** when it is completed, then press **Close** on the event.
5. Go to **Safety → Reporting → Indicators**, choose the year: LTIFR, near misses, lost-time
   injuries, commuting accidents and days without accident. LTIFR stays empty while a past month
   has no hours worked in Attendances; the missing months are listed.
6. To export the register, select the events in the list and use **Export** (XLSX).
