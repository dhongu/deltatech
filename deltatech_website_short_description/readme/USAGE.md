1. Open a product (**Sales/Website > Products > Products**) and go to the **Sales** tab.
2. Fill in the new **Website short description** field, next to the existing **Website description** — use it for a short text meant for feeds/listings rather than the full website description.
3. Use the **Publish** button in the form header (or select one or more products in the list view and run the **Publish on Website** action) to publish the product(s) directly, without having to open the website editor.
