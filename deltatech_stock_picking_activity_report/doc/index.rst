Stock Picking Activity Report
============================

The Stock Picking Activity Report module provides detailed tracking and reporting of user activities on Stock Pickings (transfers).

Configure the Stock Picking Activity Report module
--------------------------------------------------

The module is installed from the Apps menu by searching for "Stock Picking Activity Report".

Operation of the module
-----------------------

Every change made to a Stock Picking is automatically recorded, including field updates, status changes, and validation events.

To access activity reports:

1. Go to **Inventory > Reporting > Activity Records**.

|1. Reporting Menu.png|

2. By default, you'll see a list of all activities for the current month.

3. Use the **Pivot** view to analyze user performance by state and date.

|2. Pivot View.png|

4. Use the **Graph** view for a visual breakdown of picking statuses.

5. Click on any record to see the **Activity Log**, which contains the exact field changes.

|3. Activity Log.png|
