The **Stock Picking Activity Report** module provides detailed tracking
and reporting of user activities on Stock Pickings (transfers). It
captures every change, message, and stage transition, allowing managers
to monitor team productivity and warehouse operations through
comprehensive pivot and graph views.

Features
========

- **Automatic Activity Logging**: Every change made to a Stock Picking
  is automatically recorded, including field updates and status changes
  (Draft, Waiting, Ready, Done, etc.).
- **Detailed Change Tracking**: The system logs both the old and new
  values of changed fields, providing a clear audit trail of warehouse
  operations.
- **Product Movement Analysis**:

  - **Entry Product Number**: Tracks the number of products in incoming
    transfers.
  - **Exit Product Number**: Tracks the number of products in outgoing
    transfers.
  - **Internal Product Number**: Monitors quantities in internal
    warehouse movements.

- **Special Event Capture**:

  - **Validation Tracking**: Specifically records when a picking is
    validated and by whom.
  - **Chatter Messages**: Records messages posted in the picking's
    chatter.

- **Comprehensive Reporting**:

  - **Pivot View**: Analyze activities by user, state, and date.
    Measures include validation counts and chatter message counts.
  - **Graph View**: Visualize activity distribution across different
    picking states.
  - **Search & Filters**: Easily find activities for "Today",
    "Yesterday", "This Month", or "This Year".

- **User-Based Analysis**: See exactly which user performed which action
  and when, helping to evaluate warehouse staff efficiency.
