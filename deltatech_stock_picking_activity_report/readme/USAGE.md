This module works automatically once installed — no configuration is needed to start collecting data:

1. Every stock picking (incoming, outgoing or internal), field change, chatter message and validation is logged in the background into an Activity Record.
2. Go to **Inventory > Reporting > Activity Records** to review the log: list, form, pivot and graph views are available, with filters for Today, Yesterday, This Month, This Year, and group-by User/Date/State.
3. Each record shows the picking, the user, the change date/state, whether the picking was validated, whether an AWB (shipping label) was generated, and how many products moved in (Incoming), out (Outgoing) or internally.
4. Activity records older than 2 months are removed automatically by a Data Recycle rule — no manual cleanup is required.
