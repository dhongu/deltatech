1. Go to *Website > Configuration > Settings*, section *Tracking & SEO*. Check *IndexNow* and
   save: a key is generated in *Key*. To use a key you already have, paste it there and save.

   ![Website settings, Tracking and SEO section: the IndexNow setting checked, the Key field with the value 9c42dc26ca5946e4b661082db126af42 and the View key file link highlighted, with the Send all pages now link below](static/description/en/01_setare_indexnow.png)

2. Click *View key file*. The page at `https://<your-domain>/<key>.txt` shows only the key: the
   search engines read it to check that the URLs come from the owner of the site.

   ![The key file open in the browser: the page shows only the text 9c42dc26ca5946e4b661082db126af42, without the header or menu of the site](static/description/en/02_fisier_cheie.png)

3. Click *Send all pages now* once, to send every published page. A notification shows how many
   URLs were sent, or why the submission failed. From then on the scheduled action
   *Website: IndexNow* sends every hour the pages published or changed since the last successful submission; the settings show
   the time and result of the last run.

   ![Website settings after clicking Send all pages now, highlighted: the green IndexNow notification at the top right with the message URLs sent: 2, highlighted; the IndexNow setting stays checked, with the key and the View key file link](static/description/en/03_trimitere_pagini.png)
