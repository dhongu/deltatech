1. Set the *Domain* of the website (*Website > Configuration > Settings*): the URLs are sent with
   it and the key file is checked on it.
2. In the same settings, section *Tracking & SEO*, check *IndexNow* and save: a key is generated. To use a
   key you already have, paste it in *Key* (8 to 128 letters, digits or dashes) and save.
3. Click *View key file*: the page must show the key and nothing else.
4. Click *Send all pages now* once. From then on the scheduled action *Website: IndexNow* sends
   the changes every hour.
