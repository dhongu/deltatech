Tells the search engines of the `IndexNow <https://www.indexnow.org>`__
protocol (Bing, Yandex, Seznam, Naver) which pages of your Odoo website
were published or changed, so that they crawl them again in minutes
instead of waiting for their next visit. Bing also feeds the web search
of ChatGPT and Copilot.

- **Key file served by Odoo**: The key that proves the site is yours is
  generated when IndexNow is enabled and served at
  ``https://<your-domain>/<key>.txt``; a key you already have can be
  pasted instead.
- **Only what changed, every hour**: A scheduled action sends the
  published pages changed since its last run, including the content
  edited in the website builder, and the published products, blog posts,
  events, jobs and courses of the installed apps.
- **Everything, on demand**: *Send all pages now* sends every published
  page once, after the first setup or a large change.
- **Result at a glance**: The settings show the time and result of the
  last submission, with a clear message when the key file is not found
  or the URLs do not belong to the domain.
- **One key per website**: On a multi-website database each domain has
  its own key and sends only its own pages.

Google does not use IndexNow: keep submitting the sitemap in Google
Search Console.

**Data sent:** only the addresses of pages that are already public, the
domain and the key.

Configuration
=============

1. Set the *Domain* of the website (*Website > Configuration >
   Settings*): the URLs are sent with it and the key file is checked on
   it.
2. In the same settings, section *Tracking & SEO*, check *IndexNow* and
   save: a key is generated. To use a key you already have, paste it in
   *Key* (8 to 128 letters, digits or dashes) and save.
3. Click *View key file*: the page must show the key and nothing else.
4. Click *Send all pages now* once. From then on the scheduled action
   *Website: IndexNow* sends the changes every hour.

Usage
=====

1. Go to *Website > Configuration > Settings*, section *Tracking & SEO*.
   Check *IndexNow* and save: a key is generated in *Key*. To use a key
   you already have, paste it there and save.

   |Website settings, Tracking and SEO section: the IndexNow setting
   checked, the Key field with the value
   9c42dc26ca5946e4b661082db126af42 and the View key file link
   highlighted, with the Send all pages now link below|

2. Click *View key file*. The page at
   ``https://<your-domain>/<key>.txt`` shows only the key: the search
   engines read it to check that the URLs come from the owner of the
   site.

   |The key file open in the browser: the page shows only the text
   9c42dc26ca5946e4b661082db126af42, without the header or menu of the
   site|

3. Click *Send all pages now* once, to send every published page. A
   notification shows how many URLs were sent, or why the submission
   failed. From then on the scheduled action *Website: IndexNow* sends
   every hour the pages published or changed since the last successful
   submission; the settings show the time and result of the last run.

   |Website settings after clicking Send all pages now, highlighted: the
   green IndexNow notification at the top right with the message URLs
   sent: 2, highlighted; the IndexNow setting stays checked, with the
   key and the View key file link|
