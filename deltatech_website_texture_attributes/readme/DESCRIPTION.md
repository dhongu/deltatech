Key Features
============

This module enhances the product customization options on the Odoo website by introducing visual textures for product attributes.

Features:
---------

- Adds a "Texture" field to product attributes, allowing for the association of an image with each attribute value.
- Enables the display of these texture images in the product configurator on the website.
- Provides a more realistic and visually appealing way for customers to see product variations (e.g., fabric types, wood grains).
- Extends the standard eCommerce functionality for better product presentation.

Usage:
------

1. Navigate to Sales > Configuration > Attributes.
2. Select or create an attribute that you want to use with textures.
3. In the attribute value section, you will find a new "Texture Image" field.
4. Upload an image representing the texture for each value.
5. On the website product page, these images will be used instead of standard color or text selectors for the chosen attribute.
