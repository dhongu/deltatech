Key Features
============

This module provides a comprehensive "Ledger" management system for tracking and organizing documents within Odoo.

Features:
---------

- Dedicated ledger for storing information about entry and exit document numbers and descriptions.
- Automated sequence generation for document entries.
- Enhanced traceability and audit trail for various business documents.
- Easy searching and filtering of ledger records for reporting and verification.

Usage:
------

1. Navigate to the new "Ledger" menu in Odoo.
2. Create or view existing ledger entries to see document details and their assigned numbers.
3. This is useful for businesses that need to maintain a centralized record of all document references across different departments.
4. Integrated with Odoo's mail system for better communication regarding specific document entries.
