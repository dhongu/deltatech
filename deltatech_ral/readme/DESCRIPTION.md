Manufacturers that paint the same product in many RAL colors would otherwise
need one bill of materials per color, differing only by the pigment. With this
module a single bill of materials uses a generic pigment, which each
manufacturing order replaces with the real pigment of the color being
produced. The color is also kept on the lot of the finished product.

**Pigment on the manufacturing order.** A **RAL** field on the manufacturing
order holds the pigment used. When the order is created, the pigment is
chosen from the color of the product variant: the value of its attribute with
the *Color* display type gives the pigment whose internal reference contains
`RAL <value>`. The planner can change the pigment while the order is in draft
or confirmed.

**Generic pigment replaced in the components.** On the order, the component
coming from the bill of materials line with the generic pigment (internal
reference `RAL 0000`) is replaced by the pigment in the **RAL** field, with
the same quantity. The replacement is kept when the components are
recalculated, for example when the quantity to produce changes, so the stock
consumed is that of the real pigment.

**RAL on the lot.** Lots and serial numbers have a **RAL** field, shown on
the lot form and list. When Odoo generates the lot of the finished product
for an order (the **Generate Lot** / **Generate Serial** button, or the lot
created when the order is produced without one), the pigment of the order is
written on that lot.

## Configuration

- Create the generic pigment, with the internal reference `RAL 0000`, and
  the real pigments, with the internal reference `RAL ` followed by the name
  of the color value (for example `RAL White` for the value *White*).
- Create a color attribute with the *Color* display type in *Inventory >
  Configuration > Products > Attributes* (product variants must be enabled)
  and add it to the finished product.
- In the bill of materials of the finished product, set on the product
  template (no variant), add the generic pigment `RAL 0000` as a component.
- To keep the color on the lot, track the finished product by lots or serial
  numbers.

## Limitations

- The pigment is matched by a partial search on the internal reference, so
  references that contain one another (`RAL White` and `RAL White Matt`) can
  give the wrong pigment; keep the references distinct.
- The **RAL** field is written only on lots generated by Odoo for the order;
  a lot entered or selected manually on the order does not receive it.
