## Prerequisites

Before using this module, attach a data sheet or safety data sheet to a product
template via **Inventory > Products > Products** (or **Sales > Products**), using the
fields provided by the `deltatech_data_sheet` module.

## Viewing data sheets on the website

1. Navigate to your Odoo website shop (e.g. `https://<your-domain>/shop`).
2. Click on any product that has a data sheet or safety data sheet attached.
3. On the product detail page, locate the document section below the product
   description.
4. If a **Data Sheet** is attached, a **Show Data Sheet** button is displayed. Click it
   to open or download the file.
5. If a **Safety Data Sheet** is attached, a **Show Safety Data Sheet** button is
   displayed alongside. Click it to open or download the safety file.

The buttons are only visible when the corresponding document is set on the product
template. Products without attached documents show no buttons.
