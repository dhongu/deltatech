This module extends the Odoo eCommerce product page to surface product documentation
directly to website visitors. When a product has an associated data sheet or safety data
sheet (managed via the **Deltatech Product Data Sheet** module), download links are
automatically displayed in the **Documents** section of the public product page — no extra
configuration required.

**✨ Key features:**

- Adds a **Show Data Sheet** link on the website product page when a data sheet is
  attached to the product template.
- Adds a **Show Safety Data Sheet** link on the website product page when a safety
  data sheet is attached to the product template.
- The links are listed in the native **Documents** section, next to the product's own
  documents; the section is shown even when the product has no other document.
- A click downloads the PDF, also for visitors who are not signed in.
- Requires the `deltatech_data_sheet` module to manage and attach data sheets to
  products.
