This module extends the Odoo eCommerce product page to surface product
documentation directly to website visitors. When a product has an
associated data sheet or safety data sheet (managed via the **Deltatech
Product Data Sheet** module), download buttons are automatically
displayed on the public product page — no extra configuration required.

**Key features:**

- Adds a **Show Data Sheet** button on the website product page when a
  data sheet is attached to the product template.
- Adds a **Show Safety Data Sheet** button on the website product page
  when a safety data sheet is attached to the product template.
- Buttons link directly to the document, allowing visitors to open or
  download the file in their browser.
- Requires the ``deltatech_data_sheet`` module to manage and attach data
  sheets to products.

Usage
=====

Prerequisites
-------------

Before using this module, attach a data sheet or safety data sheet to a
product template via **Inventory > Products > Products** (or **Sales >
Products**), using the fields provided by the ``deltatech_data_sheet``
module.

Viewing data sheets on the website
----------------------------------

1. Navigate to your Odoo website shop (e.g.
   ``https://<your-domain>/shop``).
2. Click on any product that has a data sheet or safety data sheet
   attached.
3. On the product detail page, locate the document section below the
   product description.
4. If a **Data Sheet** is attached, a **Show Data Sheet** button is
   displayed. Click it to open or download the file.
5. If a **Safety Data Sheet** is attached, a **Show Safety Data Sheet**
   button is displayed alongside. Click it to open or download the
   safety file.

The buttons are only visible when the corresponding document is set on
the product template. Products without attached documents show no
buttons.
