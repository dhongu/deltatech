1. Go to **Settings > Technical** (or the module's own menu) and define one or more **Agreement Types**, each with a sequence (for numbering) and, optionally, a print layout (report template).
2. Create a new **Agreement**, set the partner, agreement date, final date, currency and type.
3. Use **Get Name** to assign the next number from the type's sequence.
4. Use **Open**, **Close** and **Set to Draft** to move the agreement through its states (Draft → In Progress → Terminated). Agreements can only be deleted while in **Draft**.
5. Use **Print Agreement** to generate the document from the type's configured report template.
