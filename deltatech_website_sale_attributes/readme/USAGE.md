1. Go to **Sales > Configuration > Attributes**, open an attribute and open one of its values.
2. Set the new **Visibility** field to **Visible** (default) or **Hidden**.
3. On the website shop, the attribute filter list and the product's variant selector only take into account values marked **Visible** — hidden values are excluded, and when filtering by category and search together, only the values that are actually used by products matching the current search/category are proposed.
