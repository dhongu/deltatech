Website Sale Attributes
=======================

This module enhances the product attribute display in the e-commerce
website by:

- Displaying attribute values based on determined products
- Filtering attribute values to show only those that are relevant to the
  currently available products
- Optimizing the attribute selection experience for customers

The module modifies the default Odoo behavior by filtering attribute
values in the website_sale.products_attributes template to show only
relevant options.
