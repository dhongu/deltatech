On the website shop page, open the **Sort by** dropdown above the product grid. Besides the standard Odoo options, five new criteria are available:

- **Best sellers** — products with the highest sales in the last 12 months.
- **Most Visited** — products with the most website visits.
- **Reviews** — products with the most reviews.
- **Best Review** — products with the highest average rating.
- **Availability** — in-stock products first.

These values are calculated automatically once a day by the scheduled action **Products: Update products statistics** (Settings > Technical > Automation > Scheduled Actions), so no manual action is required — just wait for the first run (or trigger it manually) after installing the module for the sort options to return meaningful results.
