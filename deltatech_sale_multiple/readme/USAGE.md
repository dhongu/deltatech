1. Open a product (Sales tab on the product template, or the "Quantity" group on the product variant form).
2. Set **Qty Minim** to the minimum quantity that can be sold — if a user enters less than this on a sale order line, the quantity is automatically raised to the minimum.
3. Set **Qty Multiple** to force the quantity to always be a multiple of this number — if a user enters a quantity that isn't an exact multiple, it is rounded up to the next valid multiple.
4. Leave either field at 0 to disable that check for the product (no minimum and/or no multiple enforced).
