Features:

- Search and delete duplicate xml anaf files (cron: Delete duplicate xml
  attachments)
- Create missing stock reordering rules (cron: Create missing reordering
  rules (0/0))
- Search and delete old pdf attachments of sale orders (cron: Delete pdf
  sale order attachments)
- All cron jobs are disabled by default and run in "dry mode" (no
  changes in the database)
- Function to cancel all stock and account moves on a sale order -
  force_cancel_order_and_moves. Must be called by server action. Create
  server action manually, for security reason

Changelog
=========

18.0.0.1.0 (2026-10-30)
-----------------------

- The batch cron jobs use the native cron progress through the new
  ``deltatech_cron_progress`` helper instead of calling ``_trigger()``
  on themselves: merge duplicate contacts / companies, normalize company
  names, delete old mail messages and delete generated PDFs (invoices,
  sale orders, pickings). A batch that makes no progress (dry run,
  failed delete, all merges failed) reports nothing remaining, so the
  job stops instead of looping.
- Merge duplicate contacts / companies: each group is merged in its own
  savepoint, so a failed merge no longer cancels the whole batch.
- Fix: *Normalize company names* updated the same companies forever,
  because names already normalized (``S.R.L.``, ``S.A.``, ...) still
  matched the selection and the batch always started at offset 0. Only
  names not yet normalized are selected now, the stored
  ``complete_name`` is recomputed, and the administrators are notified
  once, at the end.
- Fix: *Delete mail messages* never corrected the mimetype of ``.xml``
  attachments (``name = '%.xml'`` instead of ``LIKE``), failed with an
  SQL error when ``exclude_models`` was not set, and deleted the
  messages of the excluded models whenever more than one pattern was
  given (``NOT LIKE ANY`` instead of ``NOT LIKE ALL``).
