Overview

Stores the configuration of the product sold on a sale order line — dimensions, profile, colour, parts, mock-up images — as structured data, and shows it to the salesperson from a Details icon on the line.

Connectors and marketplace importers write the configuration they receive (a window configurator, a print shop's mock-ups) into one common field, config_details, instead of each inventing its own field and popup. The salesperson reads it in a popup without leaving the order.

Main features:

  • config_details on sale order lines, a JSON field copied with the line when the order is duplicated.
  • Details
    icon (ⓘ) in its own narrow column of the order lines, shown only on lines with details.
  • Popup with the details as a compact table, one row per group: values as key: value on one line, nested groups on compact lines, pictures with an Open image link.
  • Safe: every text is escaped and nothing is ever evaluated as code.
  • Reads the formats written by older importers (a JSON text, or the text of a Python list) and converts the details of a database coming from 19.0 when it is upgraded.
  • Helpers for project reports: get_html_config_details() and get_images_config_detail().

Format of the field: a list of {"name": ..., "value": ...} groups, where value is a text or a dictionary of texts, numbers or dictionaries. The key id is never shown; the keys image and src are shown as pictures.

Usage

The details are written by connectors and importers (a window configurator, a marketplace) into the config_details field of the sale order lines; they cannot be typed or edited from the interface. The module has no settings and no menu of its own.

  1. Open the order created by the connector (Sales → Orders → Quotations, or Sales → Orders → Orders once confirmed). In the Order Lines tab, the lines with a configuration have a Details icon (ⓘ, the text shows on hover), in a narrow column at the end of the row, after the amount; lines without details (a service, for instance) have no icon.
1 Quotation for Casa Verde Residence SRL, Order Lines tab: the lines Fereastră PVC 2 canate and Ușă balcon PVC have the Details icon (ⓘ), highlighted, in a narrow column at the end of the row, after the amount; the Montaj tâmplărie line has no icon
  1. Click the Details icon to open the read-only Config Details popup, a compact table with one row per group: the group name on the left, the values on the right as key: value, one after the other and never broken inside (numbers are shown like texts); each nested group gets a compact line of its own, and a group with a plain text value shows the text on the right. The id key is never shown. Close returns to the order.
2 Config Details popup of the Fereastră PVC 2 canate line: one table row per group, Identitate, Dimensiuni, Profil, Culoare, Părți, Schiță and Observații, highlighted; values such as Poziție P1, H 1400 and L 1200 mm, the nested parts with x, y and opening, the sketch with its Open image link, and the Close button
  1. Values under the keys image and src are shown as pictures that keep their proportions (src larger), each with an Open image link that opens it in a new browser tab.
3 Config Details popup of the Ușă balcon PVC line: the Machetă group with a large and a small picture of the door, highlighted, each with its Open image link

Format of the field: a list of {"name": ..., "value": ...} groups, where value is a text or a dictionary whose values are texts, numbers or dictionaries. Other values (lists, booleans, empty texts) are not shown. The order of the groups is kept; the order of the keys inside a dictionary is not kept (the database stores them sorted, shorter keys first).

The details are copied when the order is duplicated and are not printed on the standard quotation, delivery or invoice reports. Project reports can print them with get_html_config_details() and get_images_config_detail() (the image URLs of the groups).

Changelog

20.0.1.1.0 (2026-11-19)

  • Moved into the deltatech suite from the Maxima and Printoteca project repos; the technical name does not change.
  • Reads details written as a JSON text or as the text of a Python list (19.0 importers), never evaluating them; a dictionary without name / value is shown as an unnamed group; number values are shown like texts.
  • The Details button is an icon (ⓘ, text as tooltip) at the end of the line, after the amounts: between the description and the quantity it took width from those columns.
  • The popup is a compact table, one row per group: values on one line, never broken inside; nested groups on compact lines. Pictures keep their proportions, with a translatable Open image link under them; src pictures are larger, as on 19.0.
  • Upgrade from 19.0: the text column is converted to JSON before the update, instead of being dropped by Odoo.

20.0.1.0.0 (2026-11)

  • Port to 20.0 in the Maxima repo: the field is fields.Json instead of Text, the eval fallback is gone, every text is escaped, the Details button has its own column.
