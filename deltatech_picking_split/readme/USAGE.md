1. Open a transfer that is not yet done or cancelled and use the **Manual backorder**
   action (available from the transfer's form view action menu).
2. In the wizard, each product line shows the demanded quantity and a **Kept**
   quantity, pre-filled with the forecast availability; adjust the **Kept** quantity
   for any line you want to ship/receive now (it cannot be set below 0 or above the
   demand).
3. Click **Apply**: a new backorder transfer is created, a note is posted on the
   original transfer linking to it, and for every line the quantity beyond what you
   kept is moved to the backorder (lines fully kept at 0 are moved there entirely).
   Use **Cancel** to close the wizard without splitting anything.
