1. Go to **Settings > Technical > Line Counter** (menu added under the
   Technical settings menu).
2. In the wizard, select one or more installed modules in the
   **Modules** field.
3. Click **Count Lines**.
4. The wizard displays a table with the number of non-empty lines per
   module (counted in `.py`, `.xml`, `.js`, `.css` and `.scss` files;
   files under any `tests` folder are excluded) and a total at the
   bottom.
