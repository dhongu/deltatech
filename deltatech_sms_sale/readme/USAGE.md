1. Go to **Sales > Configuration > Settings**. Both **SMS Sale Order Post** and **SMS Sale Order Confirm** are enabled by default, so SMS notifications go out as soon as the module is installed.
2. **SMS Sale Order Post** sends an SMS to the customer when a sale order is posted (e.g. from the website); pick the **SMS Template** to use, or disable the toggle to turn it off.
3. **SMS Sale Order Confirm** sends an SMS when a sale order is confirmed; pick its **SMS Template**, or disable the toggle to turn it off.
4. Both settings ship with a default template ("We are glad to inform you that your order n° ... has been posted/confirmed") which can be customized like any other SMS template.
5. The SMS is only sent if the customer has a mobile or phone number on file; both settings are company-specific.
