- Open a **Contact** (an individual, not a company) — a new **Personal Data** tab appears on the form with fields for **Card ID Number**, **Card ID Issued by/at**, **CNP**, **Birthdate** and **Gender**. These are also available on the simplified "create contact" popup and on the child-contact form.
- Filling in the **CNP** (Romanian personal numeric code) automatically fills in **Birthdate** and **Gender**; conversely, changing **Birthdate** while a CNP is set recalculates the CNP's date digits and checksum. The CNP is validated on save and rejected if the checksum is invalid.
- The Contacts list/kanban search view gains **Delivery** and **Invoice** address filters, and the existing **Individuals**/**Companies** filters are restricted to top-level contacts only.
- Optional: to shorten displayed names for individual contacts (drop the parent company from the name), go to **Settings > Technical > System Parameters** and set the parameter `contact.get_name_only` to a truthy value.
