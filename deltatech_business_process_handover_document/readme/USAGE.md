1. Requires `deltatech_business_process` to be installed.
2. On a **Business Project**, fill in the **Provider Information** (provider company, representative, testers) and **Recipient Information** (recipient company, representative, testers) sections.
3. Use **Print > Handover Document** on the project to generate the "Verbal Process" (handover) PDF document, listing the process steps, developments and the provider/recipient sign-off information.
4. The document is available in both English and Romanian, following the language of the project/user generating it.
