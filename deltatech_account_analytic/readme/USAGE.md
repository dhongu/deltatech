1. Go to **Accounting > Configuration > Settings** to configure the analytic options added by this module.
2. On an **Analytic Distribution Model** (Accounting > Configuration > Analytic Distribution Models), set the **Sale team** to restrict the model to a specific CRM sales team.
3. To split an existing analytic line across several analytic accounts:

   - Go to **Accounting > Analytic > Analytic Split Templates** and define a template with the percentage breakdown per analytic account (the percentages must total 100%).
   - Open an analytic line and use the **Split** action; select the template (or enter a fixed amount), then **Prepare Lines** to generate the split lines.
   - Use **Create Analytic Lines** to confirm the split and generate the resulting analytic lines, or **Reset** to undo an amount-based split.
