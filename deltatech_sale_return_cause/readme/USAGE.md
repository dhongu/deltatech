1. (Optional) Go to **Sales > Configuration > Return Causes** to review or add the list of predefined reasons (e.g. quality issue, shipping error, client mistake). Each cause has a sequence and an active flag.
2. On a sale order, set the **Return Cause** field (found next to the salesperson) to record why an order was returned. A free-text **Return** note field also appears once a cause is set.
3. The **Return Amount** field shows the total value returned for that order, calculated automatically from the posted credit notes linked to the order's invoices. It becomes read-only once auto-calculation is active, but can be entered manually if you disable auto-calculation via the `deltatech_sale_return_cause.auto_calculate` system parameter (**Settings > Technical > Parameters > System Parameters**, set the value to `False`).
4. A daily scheduled action re-verifies and refreshes return amounts for orders placed in the last year, so the figures stay accurate even if credit notes are posted later.
5. **Return Cause** is also available as an optional column on the sale orders list, and both **Return Cause** and **Return Amount** feed into the standard Sales Analysis report (pivot and graph views), so you can analyze return trends by cause, date, or other sales dimensions.
