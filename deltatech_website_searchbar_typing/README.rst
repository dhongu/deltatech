The placeholder of a website search box types example searches, one
after another: each example is typed letter by letter, held for a
moment, erased, and the next one follows. Visitors see at a glance what
they can search for: a part code, a product name, a topic from the user
guides.

**Features:**

- Opt-in per search box: only the search forms that carry examples are
  animated. Installing the module changes nothing else on the website.
- The examples are plain text inside the search form, so they are
  translated with the page and can be edited like any other text.
- An optional prefix stays in front of every example (for instance "e.g.
  ").
- The animation stops for good as soon as the visitor clicks in the box
  or starts typing, and the original placeholder comes back.
- It does not run when the visitor asked the system for reduced motion
  (``prefers-reduced-motion``), and it stops if that setting is turned
  on during the visit.
- It waits while the browser tab is hidden or the search box is scrolled
  out of view.
- The search box keeps a stable accessible name: when the box has no
  label, the original placeholder is set as its ``aria-label``, so
  screen readers do not read every changing letter.
- It works with the standard search snippet and with the
  ``website.website_search_box_input`` template, next to the standard
  autocomplete dropdown.

Usage
=====

Add the examples inside the search form, as a hidden list with the class
``o_searchbar_typing``. Each item is one example; the optional item with
the class ``o_searchbar_typing_prefix`` is shown in front of every
example, followed by a space. Use list items (``li``), not ``span``:
Odoo translates each list item as a term of its own, while a group of
inline elements is translated as one block of HTML.

In a QWeb template that calls ``website.website_search_box_input``, the
body of the call is placed inside the form:

.. code:: xml

   <t t-call="website.website_search_box_input">
       <t t-set="search_type" t-valuef="all"/>
       <t t-set="action" t-valuef="/website/search"/>
       <t t-set="placeholder">Search the user guides</t>
       <ul class="o_searchbar_typing d-none" aria-hidden="true">
           <li class="o_searchbar_typing_prefix">e.g.</li>
           <li>e-Invoice</li>
           <li>bank statement import</li>
           <li>credit note</li>
       </ul>
   </t>

The same list can be added to a search snippet placed with the Website
Builder, from the HTML editor of the page.

The speed can be changed with data attributes on the
``o_searchbar_typing`` element, in milliseconds: ``data-start-delay``
(1500, before the first letter), ``data-type-delay`` (70, per typed
letter), ``data-hold-delay`` (1800, how long a full example stays),
``data-erase-delay`` (30, per erased letter) and ``data-next-delay``
(400, before the next example).

Choose examples that return results: a visitor who copies one should
find something.
