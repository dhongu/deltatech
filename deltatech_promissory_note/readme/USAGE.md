1. Go to **Accounting > Promissory Notes** (bilete la ordin) to create a
   new promissory note: choose **Type** (Customer or Vendor), fill in
   the **Series and number**, **Due Date**, **Amount**, **Currency**
   and link it to an **Invoice** if applicable.
2. Selecting the **Type** automatically fills in the **Issuer** and
   **Beneficiary** based on your company; selecting a partner
   auto-fills their bank account and bank from the partner's saved bank
   accounts.
3. Track the note through its lifecycle using the status buttons:
   **Cashed**, **Not Cashed**, **Cancelled**. Amount and date fields for
   cashing are recorded when a note is marked as cashed.
4. Mark a note as **Last note** to trigger a notification: when it gets
   cashed, all users in the **BO Notifications** security group receive
   a message with the note, issuer, amount and agreement details.
5. Print the promissory note report from the note's form/list view.
