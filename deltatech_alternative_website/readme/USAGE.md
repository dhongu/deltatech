1. Requires `deltatech_alternative`, `website` and `website_sale` to be installed.
2. On the eCommerce product search box, customers can type a product's **alternative/cross-reference code** (as configured via `deltatech_alternative`) and the matching product will be found, in addition to the standard name/reference search.
3. No extra configuration is needed beyond enabling alternative code search in **Website > Configuration** (inherited from `deltatech_alternative`'s settings).
