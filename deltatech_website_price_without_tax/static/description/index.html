Overview

A shop that sells to consumers and to companies usually shows prices with tax, while a company buyer wants the net price. This module adds a line with the price without tax to the product page of the website.

  • Net price line
    The price block of the product page gets a muted line Preț fără TVA: (Romanian for "price without VAT") with the amount in the website currency. The line is hidden when the amount is zero.
  • Follows the display mode
    When the website shows prices tax excluded, the line repeats the displayed price. Otherwise the product taxes are taken out of the displayed price, as if every tax were included in it.
  • Display only
    The module adds a list_price_without_tax entry to the product price data and a template that shows it. Other prices, the cart, orders and invoices are not touched.
  • Optional view
    The line is an optional view called Product Price without tax, active after installation, which can be disabled for one website.

The module depends on Website and eCommerce (website_sale); every visitor sees the line. The label is written in Romanian in the template and has no translation. The amount comes from the list_price entry, not from price, so test products that have a pricelist discount.

Versions

19.0.1.0.8 (2026-11-11)

  • Apps Store page: a fuller description (what the module does, the problem it solves, its main functions, dependencies and limits). No change in behavior.

19.0.1.0.6

  • Fix: the "Price without tax" shown on the product page was wrong when the website display mode and the tax "included in price" setting differed. With prices displayed tax included and a tax excluded from price, the gross price was shown as net (121 instead of 100); with prices displayed tax excluded and a tax included in price, the net price was reduced again (82.64 instead of 100). The net price now follows the website display mode: it is taken as is when prices are shown tax excluded, and the taxes are removed from the displayed gross price otherwise.

19.0.1.0.5

  • Own module icon, instead of the generic gears it had.

History

  • Listed on Odoo Apps as Price Without Tax on Website (was eCommerce Product Price Without Tax). The technical name deltatech_website_price_without_tax does not change.

19.0.1.0.4 (2026-09-26)

  • Fix: upgrade from 18.0 failed with "Element <xpath expr="//div[@itemprop='offers']"> cannot be located in parent view". The generic view kept its 18.0 arch in the database and had a website-specific (COW) copy. On update, the COW copy is written first and its validation combines the still-old generic view against the 19.0 website_sale.product_price. A pre-migration script now deactivates the old generic view and an end-migration script reactivates it once the new arch is loaded. The website-specific copies are left untouched, so the option stays enabled or disabled per website as the customer set it in the website editor.
