Give transfers a second, official number only when you decide to: an operation type can
carry an extra "request" sequence, and the **Allocate number** button on the transfer
takes the next number from it. Drafts, cancelled and test transfers no longer consume
numbers from the official series, so the numbered documents stay consecutive and without
gaps.

- **Second sequence per operation type**: the *Sequence on Request* field on the operation
  type, next to the standard reference sequence, sets the series used for allocated
  numbers.
- **Number on demand**: the **Allocate number** button on the transfer form takes the next
  number from that sequence and sets it as the transfer reference; the number is also
  kept in the *Request Number* field of the transfer.
- **Allocated only once**: a transfer that already has a request number, or whose
  operation type has no request sequence, is left unchanged.
- **Several transfers at once**: the action works on a set of transfers and each one gets
  its own number.
- **Protected numbering**: a transfer with an allocated number cannot be deleted, so no
  number disappears from the series.
