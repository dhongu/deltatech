1. Go to *Inventory > Configuration > Operation Types*, open an operation type and set
   *Sequence on Request* to the sequence of the official series.
2. Create a transfer with that operation type; it receives the usual draft reference.
3. When the document has to be numbered, click **Allocate number**: the transfer gets the
   next number of the request sequence as its reference.
4. A transfer with an allocated number can no longer be deleted; cancel it instead.
