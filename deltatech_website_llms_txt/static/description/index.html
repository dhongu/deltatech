Overview

Publishes /llms.txt on your Odoo website: a short Markdown summary of the site, in the llms.txt format, that ChatGPT, Claude, Perplexity and other AI assistants read to understand who you are and which pages matter, instead of guessing from the HTML.

  • Generated from the website
    The site name, a summary, the contact details of the company, the published and indexed pages (with their meta description), the shop and its categories when eCommerce is installed, and the sitemap.
  • Your words first
    A summary and a free Markdown text (delivery areas, payment, returns, what an assistant should know before recommending you) are written per website, in the llms.txt tab of the website form, full width.
  • Full control when needed
    A custom file, when filled in, is served as is instead of the generated one; the file can also be switched off per website.
  • One file per website
    On a multi-website database each domain serves its own file, with its own pages and categories.

Data published: only what is already public on the website (published pages, shop categories, the company email, phone, city and country) and the texts you write for it.

Configuration
  1. Go to Website > Configuration > Settings, section Tracking & SEO: keep the llms.txt setting checked and click Edit llms.txt.
  2. In the llms.txt tab of the website, write a one or two sentence llms.txt Summary; without it the meta description of the homepage is used.
  3. Optionally add llms.txt Details in Markdown, or a Custom llms.txt to replace the generated content.
  4. Click View llms.txt to check the file served at https://<your-domain>/llms.txt.

Versions

History

19.0.1.1.0 (2026-11-02)

  • The pages without a meta description in their SEO settings take the one set in their template (<t t-set="website_meta_description">), as the pages of a theme do: theme pages have no SEO field of their own, so they were listed without a description.
  • The summary, the details and the custom file move from the settings to a new llms.txt tab of the website form (Website > Configuration > Websites), full width, for longer Markdown. The settings keep the llms.txt checkbox, with the links Edit llms.txt and View llms.txt.
  • Romanian translation (i18n/ro.po).
  • The View llms.txt link in the settings no longer logs the warning "<a>" tag with "btn" class must have "button" role at installation.

19.0.1.0.0 (2026-10-16)

  • Initial release: /llms.txt generated per website from its pages, shop categories and company contact, with a summary, Markdown details or a fully custom file set in the settings.
