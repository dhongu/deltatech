1. Go to *Website > Configuration > Settings*, section *Tracking & SEO*, setting *llms.txt*.
2. Keep *Publish llms.txt* on and write a one or two sentence *Summary*; without it the meta
   description of the homepage is used.
3. Optionally add *Details* in Markdown, or a *Custom file* to replace the generated content.
4. Click *View llms.txt* to check the file served at `https://<your-domain>/llms.txt`.
