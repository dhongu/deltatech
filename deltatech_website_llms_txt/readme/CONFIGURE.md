1. Go to *Website > Configuration > Settings*, section *Tracking & SEO*: keep the *llms.txt*
   setting checked and click *Edit llms.txt*.
2. In the *llms.txt* tab of the website, write a one or two sentence *llms.txt Summary*; without
   it the meta description of the homepage is used.
3. Optionally add *llms.txt Details* in Markdown, or a *Custom llms.txt* to replace the generated
   content.
4. Click *View llms.txt* to check the file served at `https://<your-domain>/llms.txt`.
