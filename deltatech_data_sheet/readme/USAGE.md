1.  Open a **Product Template** and locate the new **Data Sheet** group next to the Description on the main form.
2.  Upload a PDF in **Data Sheet** (technical/commercial data sheet) and/or **Safety Data Sheet** — both are attachment fields, so use the paperclip/upload widget to pick the file.
3.  These attachments are then available wherever the product's data sheets are needed (for example by `deltatech_data_sheet_website`, which exposes download links on the website product page).
