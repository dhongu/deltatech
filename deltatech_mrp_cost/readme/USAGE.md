1. Go to **Manufacturing > Products > Bills of Materials**, open a BoM and fill in the new **Costs** tab: **Overhead**, **Utility consumption** (per hour), **Net Salary Rate**, **Salary Contributions** and **Duration** (hours). These values are the default extra costs for productions created from this BoM.
2. When a Manufacturing Order is created from that BoM, the same values are copied onto the order (scaled to the order's quantity/duration) and can be reviewed or adjusted on the order's own **Costs** tab.
3. These extra costs are automatically added to the computed production cost (**Production Amount** / **Calculate Price** fields) alongside the cost of consumed components, so the finished product's valuation reflects overhead, utilities, and labor, not just raw materials.
