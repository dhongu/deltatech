-## Manufacturing Cost Management

This module extends Odoo's Manufacturing (MRP) functionality by adding comprehensive cost calculation and tracking capabilities for production orders.

### Key Features:

- **Additional Cost Fields**: Adds overhead costs, utility consumption, net salary rates, and salary contributions to both Bills of Materials (BOM) and Manufacturing Orders
- **Cost Calculation**: Automatically calculates total production costs including:
  - Raw materials costs
  - Overhead amounts
  - Utility consumption based on duration
  - Labor costs (net salary + contributions)
- **Cost Categories**: Supports categorized cost tracking:
  - Raw materials
  - Semi-finished products
  - Packaging materials
- **Production Duration**: Tracks production time and applies time-based costs
- **Real-time Cost Updates**: Automatically updates production order costs when BOM is selected
- **Cost Analysis Views**: Provides detailed cost breakdown and analysis reports
- **Price Calculation**: Computes actual production prices based on consumed materials and additional costs

### Benefits:

- **Accurate Costing**: Get precise production costs including all direct and indirect expenses
- **Better Pricing**: Make informed pricing decisions based on real production costs
- **Cost Control**: Monitor and control manufacturing costs effectively
- **Financial Reporting**: Enhanced cost reporting and analysis capabilities
- **Process Optimization**: Identify cost optimization opportunities through detailed cost breakdowns

The module integrates seamlessly with Odoo's standard MRP workflow while providing advanced cost management features essential for manufacturing businesses.
