1. Requires `deltatech_business_process` and `website_slides` to be installed.
2. On a **Business Project**, enable **Auto Generate Doc** and select the eLearning **Channel** to publish the generated documentation slides to; check **Website Published** to make the project's documentation publicly visible.
3. On a **Business Process**, a **Slide** is generated (linked via `slide_id`) that renders the process description and its steps as a table-of-contents page (each step becomes a navigable section); check **Website Published** on the process to publish that specific page.
4. Visit the eLearning channel on the website to browse the generated business process documentation, with a sticky sidebar linking to each step.
