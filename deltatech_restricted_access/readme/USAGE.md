This module is technical and is typically installed as a dependency for legacy Deltatech configurations. It adds an **Edit sensible data** security group that restricts who can rename **Product Category**, **Stock Location**, and **Unit of Measure** records.

1. Go to **Settings > Users & Companies > Users**.
2. Open a user and, under access rights, assign the **Edit sensible data** permission to authorize them to rename these records.
3. Users without this permission can still view Product Categories, Stock Locations and UoMs, but attempts to change their name are blocked.
