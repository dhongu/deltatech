Key Features
============

This module extends the standard Odoo replenishment functionality by allowing users to specify a supplier directly in the replenishment wizard.

Features:
---------

- Adds a "Supplier" field to the product replenishment wizard.
- Enables the selection of a specific vendor from the list of product suppliers.
- Streamlines the process of creating purchase orders from the replenishment screen by pre-selecting the preferred vendor.
- Improves inventory management by providing more control over the source of replenishment.

Usage:
------

1. Go to Inventory > Products or any view where the "Replenish" button is available.
2. Click on "Replenish" for a product.
3. In the wizard, you will see the new "Supplier" field.
4. Select the desired supplier and proceed with the replenishment.
