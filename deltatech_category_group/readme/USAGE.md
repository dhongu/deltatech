1.  Go to **Inventory > Configuration > Products > Category options** and open **Category types** or **Category classes** to create the grouping values you need (each is just a name with a sequence).
2.  Open a **Product Category** (Inventory/Sales > Configuration > Product Categories) and set its **Category type** and **Category class** in the new fields on the category form.
3.  These two fields are then available for filtering and grouping (**Group By**) on:
    *   the Product Category search view,
    *   **Stock Quant** (Inventory > Reporting),
    *   the **Sale Margin** report,
    *   the **Account Invoice** report (Accounting reporting).
