1. Go to **Sales > Configuration > Settings**, find the **Send followup** setting (in the Invoicing section) and enable it, then choose the e-mail template to use (defaults to **Sale order: send followup**).
2. On a sale order, set the **Days Send Followup** field (visible in the order's Other Info group) to the number of days after the order date the followup should go out; the **Date Send Followup** field is computed automatically from the order date and this value, and can also be edited directly.
3. A daily cron job (**Sale followup**, inactive by default — enable it under Settings > Technical > Automation > Scheduled Actions) checks all orders whose followup date has been reached and sends the followup e-mail automatically; the followup fields are cleared on the order afterwards so it isn't sent twice.
4. To send the followup immediately for a specific order, open the sale order and use the **Send Followup** action (Action menu / gear icon on the order list or form).
