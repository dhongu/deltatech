Shop staff often need to find the point of sale orders that contain a
given item. This module adds a *Product* option to the search of POS
orders, so an order can be found by what was sold.

- **Product search option**: Typing in the search box of the POS orders
  offers a new *Product* option, placed right after the partner option.
- **Search on order lines**: The option lists the orders that have at
  least one line whose product matches the typed text. The match is
  partial and ignores upper and lower case.
- **Search view only**: The module changes nothing but this search view.
  It has no Python code, no new fields, no menus and no access groups.

The module depends on *Point of Sale* (``point_of_sale``) and extends
its standard POS order search view, so it applies wherever that view is
used. It does not add a product column to the list or to any report, and
it has no settings.

Use Cases / Context
===================

Part of the Terrabit POS Ecosystem
----------------------------------

This module is a small standalone addition to standard
``point_of_sale``. It is designed to work alongside the rest of the
Terrabit POS suite and the official Romanian fiscal compliance modules,
without any overlap:

- **deltatech_pos** / **deltatech_pos_base** — print fiscal receipts and
  drive cash management on a certified cash register
- **deltatech_ecr_connect** — shared fiscal document model, ECR format
  converter and Terrabit Connect sender
- **deltatech_pos_stock** — shows available stock directly in the POS
  interface
- **deltatech_pos_price_sync** — pushes live product price changes to
  already open POS sessions
- **deltatech_pos_fix** — corrects POS total calculation for
  tax-included fiscal position mapping
- **l10n_ro_pos_fiscal_compliance** — AMEF fiscal receipt tracking, Z
  report reconciliation and session blocking
- **l10n_ro_anaf_d394_pos** — reports POS fiscal receipts in the D394
  (op. 2) declaration to ANAF
- **l10n_ro_pos_returns** — dedicated return invoice and cash register
  line for every POS return
