## Managing Credentials

Only users with the **Administrator** role (`base.group_system`) can access the
Credentials menu.

1. Go to **Settings > Users & Companies > Credentials**.
2. Click **New** to create a credential entry.
3. Fill in the **Name** (required) and, optionally, a short **Code** used by other
   modules to look up this record programmatically.
4. Choose the **Access Type**:
   - **User and password** — enter the **Username** and **Password** (masked).
   - **Client ID and Client Secret** — enter the **Client Id** and
     **Client Secret / API key**.
   - **Access token** — enter the **Access Token**.
5. Save. The credential is now available for reference by integrated Deltatech modules.

To edit or revoke a credential, open the record from the list view and update or delete
it as needed.
