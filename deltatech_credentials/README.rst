**Deltatech Credentials** provides a centralised store for external
service credentials within Odoo. Instead of scattering API keys, tokens,
and login pairs across system parameters or configuration files,
administrators can manage all access data in one secure location —
available directly under **Settings > Users & Companies > Credentials**.

**Key features:**

- Store credentials for any external service with a descriptive name and
  optional code.
- Three access-type modes: **User / Password**, **Client ID / Client
  Secret (API key)**, and **Access Token** — only the relevant fields
  are shown for each mode.
- Password field is masked in the UI for security.
- Access restricted to Odoo Administrators (``base.group_system``) out
  of the box.
- Designed as a shared dependency: other Deltatech modules
  (integrations, EDI connectors, API bridges) can reference
  ``access.credentials`` records to retrieve their credentials
  programmatically, keeping secrets out of module settings.

Usage
=====

Managing Credentials
--------------------

Only users with the **Administrator** role (``base.group_system``) can
access the Credentials menu.

1. Go to **Settings > Users & Companies > Credentials**.
2. Click **New** to create a credential entry.
3. Fill in the **Name** (required) and, optionally, a short **Code**
   used by other modules to look up this record programmatically.
4. Choose the **Access Type**:

   - **User and password** — enter the **Username** and **Password**
     (masked).
   - **Client ID and Client Secret** — enter the **Client Id** and
     **Client Secret / API key**.
   - **Access token** — enter the **Access Token**.

5. Save. The credential is now available for reference by integrated
   Deltatech modules.

To edit or revoke a credential, open the record from the list view and
update or delete it as needed.
