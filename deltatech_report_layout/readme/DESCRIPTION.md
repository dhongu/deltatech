Customized Report Layouts and Styles
====================================

This module provides specialized report layout styles for Odoo, allowing businesses to customize the appearance of their printed documents (Invoices, Quotations, Purchase Orders, etc.) with more modern and professional designs.

Key Features
============

1.  **Multiple Predefined Layouts**:
    *   Adds several custom report template styles (Style 1, Style 2, etc.) to the system.
    *   Provides more flexibility than the standard Odoo report layouts by offering different header, footer, and body designs.

2.  **Centralized Layout Configuration**:
    *   Includes a dedicated configuration for selecting and managing report layouts across the entire Odoo instance.
    *   Ensures consistent branding and styling for all corporate communications.

3.  **Modern Web Asset Integration**:
    *   Leverages standard Odoo web and report assets for optimal performance and compatibility with Odoo's PDF generation engine.

Odoo Online
===========

The module contains no Python code, only views, report templates and styles. Besides
Odoo.sh and on-premise installations, it can be used on Odoo Online (Custom plan):
download the zip and load it from **Apps > Import Module**.
