Sale Order Pickup List Report
============================

This module provides a specialized **Pickup List** report for Sales Orders in Odoo. It's designed to streamline the warehouse operation process by providing a clear and efficient list of items to be picked from inventory for specific sales orders.

Key Features
============

1.  **Dedicated Pickup Report**:
    *   Adds a custom **Pickup List** (or similarly named) report action to the Sales Order model.
    *   Includes essential information for warehouse pickers such as **Product Name**, **Quantity**, and **Location**.

2.  **Inventory Integration**:
    *   Works in conjunction with the `sale_stock` and `deltatech_stock_inventory` modules to ensure accurate stock information.
    *   Helps inventory teams quickly identify the items that need to be picked and moved for customer orders.

3.  **Efficiency and Accuracy**:
    *   Provides a simple, easy-to-read layout to minimize picking errors and improve warehouse throughput.

Usage
=====

1.  Navigate to **Sales > Orders**.
2.  Open or select one or more Sales Orders.
3.  Click the **Print** menu (usually at the top of the form or list view).
4.  Select the **Pickup List** (or similar) report to generate the document.
5.  Print the PDF and use it in the warehouse for the picking and fulfillment process.
