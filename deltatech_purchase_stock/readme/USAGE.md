This is a technical module with no direct user interface — it has no views or
settings. It tags purchase orders generated by automatic replenishment
(reordering rules, MTO, etc.) internally with a `from_replenishment` flag, and
makes sure that replenishment only reuses/creates purchase orders that were
themselves generated by replenishment, keeping them separate from purchase
orders created manually by a buyer. No action is required from users.
