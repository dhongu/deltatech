Overview

Replenishment can add its lines to an existing draft purchase order of the vendor, including one a buyer is preparing by hand. This module marks the purchase orders that replenishment creates and stops replenishment from using any other order.

  • Replenishment flag
    Purchase orders created by a stock rule, for example from a reordering rule, get the from_replenishment flag set automatically.
  • Manual orders stay clean
    The search for an existing order to add lines to gets one more condition: the order must carry the flag. Orders without the flag are never used.
  • Replenishments still merge
    Successive replenishment needs of the same vendor still go into one flagged order, as the module's tests check.
  • Existing orders
    Orders created before the installation carry no flag, so replenishment does not add lines to them.
  • No screen
    The module adds no view, menu or setting, and the flag is not shown on the purchase order form.

The module depends on purchase_stock and has no access rules of its own. The flag is never cleared, so a flagged order stays open to replenishment even after a buyer adds lines by hand.

Versions

19.0.1.0.1 (2026-07-29)

  • Reuse an existing reordering rule in the tests: deltatech_auto_reorder_rule creates one on every new product, and only one rule is allowed per product, location and company, so creating another one broke the tests when both modules are installed.

19.0.1.0.0 (2026-07-29)

  • Port of the module from 18.0. The from_replenishment flag on purchase.order and the stock.rule._make_po_get_domain override keep replenishment purchase orders separate from the ones a buyer creates manually.
  • On 19.0 the core grouping of replenishment needs is driven by res.partner.group_rfq. With group_rfq = Always a procurement would otherwise be merged into any draft purchase order of the vendor, including manual ones — this module prevents that.
  • Added tests covering the flag on generated orders, the merge between successive replenishments and the isolation from manual draft orders.
