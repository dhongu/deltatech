1. Go to **Settings > Companies > Companies**, open a company, and use the new **Warehouse** tab to set a **Default Warehouse** and a **Default Supplier** for that company.
2. Click **Set supplier for all products** on that tab to bulk-assign the default supplier as a vendor on every purchasable product that does not already have one — useful for a quick initial setup of vendor pricing.
3. On **Inventory > Configuration > Warehouses**, two extra picking types can be set: **Type prod consume** and **Type prod receipt**, used to identify the internal transfers linked to manufacturing consumption and production receipts.
4. On a product's **Inventory** tab, a new **Scrap** field lets you record an expected consumption loss factor (e.g. 0.1 = 10% loss).
