Restricts who can see the **Sales Analysis** (Sales \> Reporting) and
**Invoice Analysis** (Accounting/Invoicing \> Reporting) screens,
independently of any other access a user already has (Salesperson,
Invoicing, Accounting...).

Two new groups control visibility:

- **Rapoarte Vânzări/Facturi: doar propriile înregistrări** - sees only
  his own records (Salesperson on the order / invoice).
- **Rapoarte Vânzări/Facturi: toate înregistrările** - sees every
  record.

A user assigned to neither group sees no data at all in these two
reports, and the corresponding menu entries are hidden for him. Nobody
is granted either group automatically - assignment is manual, from
Settings \> Users.
