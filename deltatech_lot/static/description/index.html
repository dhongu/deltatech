Overview

Generates lot numbers on supplier receipts and shows where each lot is stored.

  • Lots generated on validation
    When a receipt from a vendor (or a dropship) is validated, every line of a product tracked by lots that has no lot number gets the next number of the Serial Numbers sequence, one lot per line. Lots typed by the user are kept.
  • Lot location
    The Location field of the lot shows the location that holds all its stock (empty when the lot is spread over several locations), on the lot form for every inventory user and as a column in the list of lots.
  • Search by location
    The list of lots can be searched by Location.

Usage

  1. Track the product by lots: open the product (Inventory > Products > Products), tab General Information, tick Track Inventory and choose By Lots.

  1. Open the receipt from the vendor (Inventory > Operations > Transfers > Receipts), in the Ready state. The receipt operation type must have Create New ticked in its Lots/Serial Numbers group (the default for receipts).

  1. In Details, the Lot/Serial Number column can stay empty; split the quantity over the storage locations in Store To if needed. Type the vendor's lot number only on the lines where it must be kept. Save and press Validate.

  1. The receipt is done and every line without a lot got its own lot number from the Serial Numbers sequence.

  1. In Inventory > Products > Lots / Serial Numbers, remove the default Location grouping: the Location column shows where each lot is. A lot spread over several locations has no location.

  1. The lot form shows the same Location. Changing it moves the stock of the lot when it is all in one location.

  1. Search the lots by location: type the location and choose Search Location for. Only the lots held entirely in that location are listed.

Lot numbers are generated only on receipts and dropships, only for products tracked by lots (not by serial numbers), and always from the general Serial Numbers sequence, not from the custom prefix set on the product.
