Overview

Loads product images from a web address instead of a file: paste the address of the image (https://...) and Odoo downloads it.

  • Main product image
    The address pasted in Image File Name (product form, tab Sales) sets the product image; the field then keeps only the file name.
  • Extra images
    The address pasted in the Image Name of an extra image (Ecommerce Media) loads that image.
  • Import
    Updating existing products by import with the Image File Name column loads their images.
  • Safe download
    Only public http/https addresses are fetched, each redirect is checked, the answer must be an image of at most 10 MB, and only users allowed to edit products can trigger it.

Usage

  1. Open the product (Website > eCommerce > Products), tab eCommerce. In the Shop group, paste the address of the image, starting with https://, in Image File Name.

  1. Leave the field: Odoo downloads the image and sets it as the product image, and the field keeps only the file name. Save the product. If the address stays in the field, the image could not be loaded.

  1. For an extra image of the product (Media), paste the address in its Image Name and leave the field: the image is downloaded in the same way. Press Save in the image window, then save the product.

  1. Check the product page in the shop (Go to Website): the main image and the extra image come from the addresses.

Updating existing products by import (with their ID column) loads the images too, when the Image File Name column holds web addresses. Products created by the import keep the address as text, without image.

Only public http/https addresses are fetched, the answer must be an image of at most 10 MB and only users allowed to edit products can trigger the download.

19.0.1.0.5 (2026-10-17)

  • Fix: saving or renaming a product image, or setting the image file name on a product, no longer fails with AttributeError on servers with Werkzeug 3 (Python 3.12+); URLs are now detected with the standard library.

19.0.1.0.4 (2026-10-07)

  • Security: loading a product image from a URL no longer lets the server reach internal addresses (SSRF). Only public http/https hosts are fetched, every redirect is revalidated, the response is limited in time and size and must be an image, and only users allowed to edit products can trigger the download.
