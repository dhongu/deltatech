Sale Pallet Website
===================

This module extends pallet sales functionality to the Odoo eCommerce
platform, allowing for better management and display of products sold by
pallets on the website.

Key Features
============

1. **Pallet-Specific Displays**:

   - Enhances the website product pages to show information related to
     pallets.
   - Optimizes the user experience for bulk purchasing or items
     typically sold on pallets.
   - Allows customers to see the total price of their order including
     the cost of the pallets.

2. **Integrated Pallet Logic**:

   - Works in conjunction with the ``deltatech_sale_pallet`` module to
     ensure consistent logic between the backend and frontend.
   - Handles pallet-related constraints and pricing if applicable during
     the checkout process.

3. **Configurable Categories**:

   - Leverages the "Pallet" flag on product categories to identify which
     items should follow pallet sales logic on the website.

Usage
=====

1. Go to **Inventory > Configuration > Product Categories**.
2. Open a category and ensure the **Pallet** checkbox is enabled.
3. Products within this category will now have enhanced pallet
   information or logic applied on the eCommerce store.
4. Browse the website to view how these products are presented to
   customers.
