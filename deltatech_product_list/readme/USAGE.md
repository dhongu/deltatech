1. Go to **Sales > Products > Product List** (new menu added under the
   Products catalog).
2. Create a new Product List: give it a **Name**, define which products
   belong to it using the **Filter** domain editor (defaults to
   "Can be Sold"), and set a **Limit** on the number of products
   returned (default 80).
3. Each list is company-specific (or shared if no company is set) and
   can be archived when no longer needed.
4. Use these lists wherever a curated/filtered set of products is
   needed (e.g. as a reusable product selection for other modules or
   reports built on top of `product.list`).
